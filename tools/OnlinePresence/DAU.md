# 日活 DAU

按北京时间自然日、现有安装标识去重，收到有效 `/v1/heartbeat` 即算当天活跃。仅覆盖自愿开启在线统计的玩家；安装标识不是已认证 Steam 账号，重装更换标识会分开计数。昵称、角色和存档切换不增加同一安装的日活。

SQLite `daily_active` 每天每安装一条首次活跃分钟，保留 90 天。`dau_coverage` 记录分钟级采集覆盖；初始化时间保存在 `dau_settings`，重启不重置。旧 durations 仅有最后在线时间，无法回填历史 DAU，故不回填。

认证接口 `/api/dau` 提供每日曲线和今日累计。日环比对比昨天、周同比对比上周同日，双方均截止到北京时间今天已完成的同一分钟。任一侧缺少完整采集时比较值为未知；基期零可显示人数差，百分比未知。当天曲线点包含当前分钟，比较值排除未完成分钟。

服务每分钟原子写入 `data/public-metrics/dau.json`（只有汇总，无安装标识）。日志服务只读挂载该子目录；超过三分钟未更新显示延迟。后台折叠面板提供 7/30/90 天平滑曲线与每日明细，未知日期留空，部分采集标黄，真实零保留。

验证：`node --test dau.test.mjs startup.test.mjs` 覆盖去重、午夜切日、重启保留、同期分钟对齐、缺口、零基数、清理与心跳接入/管理鉴权。日志服务 `python -m unittest test_dau.DauTests` 覆盖共享快照、登录、缺失和过期状态。
