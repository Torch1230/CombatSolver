# Combat Solver v0.28.3 战损停止与路线信息

- 设置 > 常规新增“可接受战损上限（HP）”，默认 `0`。完整胜利路线达到设定的战损范围后会停止继续搜索，减少高血量战斗的等待时间。
- 路线详情现在会显示造成击杀的卡牌、药水、能力、遗物、毒、荆棘和球等来源；召唤或重建的敌人也能正确显示名称。
- 有动作的回合现在显示“结束回合”，只有空过回合才显示“直接结束”；回合结算造成的击杀也会显示在对应回合。
- 保钱策略在敌人携带被盗资源时会优先保留追回资源的路线，减少错过金币的情况。
- 修复后台搜索偶发因怪物名称处理问题而失败的情况。

适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。
