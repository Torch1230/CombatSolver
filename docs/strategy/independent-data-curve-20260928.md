# 固定家族留出的数据量对照

增加不同战斗根使留出排序损失略降，但继续增加没有单调改善，唯一完整候选仍丢失旧胜局。现有证据不支持“只要更多随机数据就能替换手写算法”。学习模型仍不默认启用，最终测试未打开。

## 设计与隔离

复用v46的276个训练根、100个内部留出根、9个完整留出遭遇家族和同一层级指标。固定五角色条件模型、512行/根、线性基础与秩8/L2=1交互项，不重新扫描正则系数。276根的原模型与留出审计输入、拟合及推理均未改变，直接复用成功证据；v48风险修复只改变未来采集准入，不改变这些既有可信观察的拟合或推理。

从已停止并冻结的r6任务585条记录中排除145条无有效偏好/失败记录、102条学习模型参与生成的记录、101条属于内部留出家族的记录。后一类即使卡组不同也不能进入内部训练；学习模型的历史训练可能接触内部留出，不能仅按当前场景做表面隔离。

剩余237个经典教师战斗根与旧376根核对两个完整根戳，没有重复。新增ID使用来源命名空间；原始观察摘要逐一核对。按固定角色/章节/遭遇类型轮转得到嵌套118和237根前缀，形成394和513根两档，均通过内部完整家族/近牌组及外部训练/开发/最终测试三对审计。基础项、词表支持度及因子尺度仍只在对应训练侧拟合。

新增237根来自26个遭遇家族，原276根来自25个；新增家族仅 `QUEEN_BOSS`。这是增加构筑覆盖和不同随机战斗根，不能称为新增237个独立遭遇家族。来源种子也不同，未做多次随机子集重复，因此是实际覆盖曲线，不是严格的样本数量因果估计。

## 留出指标

按角色→遭遇家族→根等权平均。准确率将平局计半，不是游戏胜率。每档的原始数据来自相同有效标签合同，512行上限和128步线性拟合规则不变。

| 训练根 | 线性损失 | 交互损失 | 线性排序准确率 | 交互排序准确率 |
| --- | ---: | ---: | ---: | ---: |
| 276（复用） | .430664 | .427955 | 83.4168% | 82.8731% |
| 394 | .426216 | .424973 | 83.5168% | 82.8188% |
| 513 | .427458 | .425133 | 83.7120% | 83.5509% |

按预先固定的最小损失规则选中394根交互模型。没有按角色拼接最有利的头，也没有因513根准确率较高临时改变选型指标。最优损失比276根改善约.00298，准确率没有同步提高；不是稳健实战优势或无偏最终测试结论。两个内部拟合的五个头均收敛。

394/513根导出分别44.79/61.55秒，拟合进程6.76/8.51秒；完整模型成本分别51.55/70.06秒。外部拟合峰值RSS约0.665/0.866GiB，C#导出约2.31/2.99GiB，不将不同进程峰值相加。

## 后续方向与工程边界

完整候选的五个线性基础实际仅有22、27、24、29、31个非零系数，虽然每头有数千个观察列。当前128次贪心坐标更新会多次更新同一字段；更多训练根不等于学会更多条件关系。这是下一轮检查拟合方式的具体线索，不是已经证明欠拟合或承诺换优化器就会更强。

本轮没有改动运行或训练器源码，复用v48同源码构建、原生合同、222文件两端门禁及五文件部署；不重复这些已完成检查。后台r7继续至08:00，单次拟合仍最多20分钟，最终测试和自动启用保持关闭。完整研究材料在 `.local/objective-search/v49/`，[结构化证据](independent-data-curve-20260928-evidence.json)记录隔离、成本、选型与实际开发结果。
