# 长期能力牌定向补采对照

定向补采没有优于随机替换对照。随机组的留出排序略有改善，但唯一完整候选仍有两场实战退化，没有达到替换旧算法的要求；运行默认和最终测试封存状态不变。

## 采集与隔离

从固定内部394根训练集选择40个原教师可靠胜利、至少持续四回合的不同父根，每角色8个。保留原生解析配置的其他牌、遗物、药水、升级、遭遇及难度，只替换一个生成牌槽。每对使用同一个新种子，一组放入该角色的原版能力牌，另一组由原生牌池随机抽取。目标牌仅决定采集构筑，名称和效果来自当前游戏表，不把任何手写牌分或旧路线分作为标签。

目标包括各角色的资源、持续成长和延迟伤害机制；亡灵契约师包含死亡之舞等。所有父根来自内部训练侧，未用内部100根留出或外部开发的轨迹作教师。新根重新核对原生装备、两个完整根戳、观察8及终局见证，并通过完整遭遇家族和近牌组隔离；相关父子根始终属于同一训练分区，不能把80个派生根称为80个独立战斗家族。

四路采集80场共356.21秒，全部完成，无隔离失败。能力组40场中34场可靠胜利、33场有偏好、21,518行；随机组35场可靠胜利、34场有偏好、19,740行。两组均有有效偏好的31对进入拟合，排除任一组缺少偏好的9对；没有按输赢或新模型表现选择配对。新增能力组的8个亡灵契约师根中7个确实观察到目标能力，出现次数本身不证明获得了充分的因果监督。
