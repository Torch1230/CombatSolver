# 连续结果估值、场景支持度与时间边界修正

目标仍是替代手写中途估值，达到更好的决策或同质量下明显更快。本轮从 `45366d93` 继续。模型只在离线DOP1/Disabled药水入口加载，生产自动搜索尚未替换。

## 研究与实现

先检查v27的原始偏好来源：不同资源负担51525对、胜负不同16439对；仅后续动作数不同约4009对。它们是采样前的同池唯一对，不能等同拟合时61796对的分布。少出牌标签并非数量上的主要来源，不能据猜测直接移除。

40根、37根有效监督共出现9936个字段。v28在原64棵深度6树之前，用128步坐标Newton提升学习线性基础项：梯度来自同根偏好对，按各列的加权差值尺度归一化，系数折回原始观测单位。根内常量的差值为零，不能被线性部分误学成边际收益；原树学习剩余偏好与上下文条件变化。没有人工指定HP/卡牌/遗物加分。

方法参考[阶段加性梯度提升](https://doi.org/10.1214/aos/1013203451)的通用思路；线性基础加成对残差树是本项目的实验设计，该论文不证明这里的搜索质量会提升。线性外推能力也不是泛化保证。

模型协议升为schema7，观察语义保持schema6，因而可复用原始数据而不假装旧模型二进制兼容。编译保留线性和树所需字段的并集；同时导出纯线性消融产物，不增加玩家模式。

v28有35个线性项，其中26个非零字段只在至多两个训练根中出现。这是稀疏支持的直接证据，尚不是其造成每个错误的因果证明。v29进一步要求字段至少在三个有偏好的真实根中出现，线性与树共用同一字段集合；计数按字段存在而非非零值，显式零仍是观察。小于三根的玩具合同使用实际根数。此门槛只约束训练，不产生新的卡牌价值表，也不在推理时读取训练集。

新增 `refit.py` 复用观察但继承全部已有成本；清单路径相同还不够，底层请求/原生装备必须与原采集摘要相同。它保存观察文件摘要，并以剩余1800秒总额给拟合子进程设硬截止。

## 修正时间观测与保路诊断

发现旧宿主只在Evaluate入口更新 `timeBoundaryObserved`，Coordinator常保留初始false；新颖性的独立时间停止也没有进入该值。本轮统一监听回合层和新颖性时间日志，并独立写入 `search-budget-boundaries.json`，保留原完成/开局/路径观察回调。

直接检查覆盖：Coordinator短时间请求报告一次回合层时间停止且总标志true；已知资源前缀根报告一次新颖性时间停止，所选结果仍是正常完成，但总标志正确为true；无时间停止的Evaluate诊断保持false。历史原始指标不改写，v24/v27报告的“无时间边界”结论撤回。该修正不修改搜索预算或排序。

在摄政王验证根上用纯线性模型、单Evaluate/Beam24/3000节点、最多3000条观察检查剪枝。18个完整候选池均没有重复状态占据多个已选名额，因此该前缀没有支持“去重遗漏是退化根因”的证据。观察只作诊断，不用于性能比较或模型训练。

源码确认实验Prune入口也绕过了旧搜索的额外保路和已有完整结果下界；这不是单纯替换一个排序函数。尚未改动这些结构，不能把所有差异归因于模型，也不能声称恢复其中任一项必然改善质量。
