# 有界纠错查询的动作覆盖对照

更多首动作类别没有优于旧查询增补对照。实验选样改动已撤回；按预定规则获选的旧查询增补模型，在五场开发实战中一场改善、两场退化，仍未启用。模型内部排序进步不能替代实际决策验收。

## 改动与配对

原查询只比较某动作深度的末位保留前缀与最高分丢弃前缀。实验保留首对的原规则，后两对优先查询尚未覆盖、且在保留队列中较少出现的首动作类别，并与最高预测分的保留前缀配对。类别只由动作种类和卡牌/药水ID组成，不是价值分数；完整选择、目标、升级和实例身份仍由原可执行前缀保存。

上限仍为三个动作深度、六条前缀，教师合计六秒、单条至多1,000节点/1,500毫秒；未知仍未知，不把找到失败后缀解释为该状态无解。状态观察、节点生命周期与文件编排保持分离，没有新增玩家模式或推理预算。

从此前v59训练侧固定60父根中，事前选择原查询数至少4的全部40根，角色数量为7/5/8/8/12。每根在v67原查询与v69覆盖查询各跑一次，共80次；同请求、牌组、遗物、种子、双完整根戳，生成轨迹的模型固定为仅用内部516根拟合的v54模型。父数据和模型祖先均再次审计内部100根、外部15根和最终5根家族/近牌组隔离。

80次均成功，采集墙钟380.28秒；原查询40根有偏好，新查询39根有偏好，39对共同准入。每根原始观察与新增轨迹由既有C#入口统一分组和抽样，只分配一次根权重，内部/完整训练规模仍为516/616。

五对采集的主路线发生变化，其中四对主要质量不同，均记录到时间停止，工作量也不同。因此这是一组完整采集流程对照，不能把结果全部归因于纯粹的选样类别变化，也不据此报告提速。
