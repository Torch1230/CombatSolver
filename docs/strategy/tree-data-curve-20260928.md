# 固定树模型的新数据量对照

从394根增加到516根略微改善了留出排序，继续增加到638根反而回落。唯一完整候选的五场实战与前一轮相同，仍丢失一场旧胜局；新增数据尚未解决策略缺口，模型未启用。

## 数据快照与隔离

在夜间r7继续采集时，一次性复制其原子状态文件，只读取已经完成且带摘要的观察文件，不读在写入中的产物，也不修改运行任务。冻结快照892条记录，排除214条无有效偏好记录、161条学习模型轨迹、155条内部留出家族记录及与原494根完整训练侧重复的118个真实根。学习轨迹可能间接见过内部留出，不能混入这次选型。

剩余244根按固定哈希和角色均衡顺序构造嵌套前缀：394+122=516，以及394+244=638。两份完整训练集分别616与738根，均只在选型后才允许重拟合。所有原始观察摘要、实际装备、两个完整根戳、完整家族及同角色近牌组隔离重新核对。638根内部训练仍仅26个遭遇家族；根数增长不等于家族多样性同幅增长，也不是重复抽样的因果学习曲线。
