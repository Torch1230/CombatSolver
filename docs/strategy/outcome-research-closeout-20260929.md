# 学习评分与统一搜索：实验收尾

**不建议合入。本分支仅用于探索可行性，不作为生产替换或性能提升承诺。** 用户要求完成本期 v86 测试后停止继续开发、采集和训练，保留中文正式实验性 PR 供审阅。学习模型仍未默认启用。

本文件是整个研究分支的收尾入口；各历史实验文档保留当时的状态，不能把其中的“下一步”理解为仍在运行的任务。v86 的 100 场 / 400 次搜索现已全部完成并回收进程：核心 15 改善、72 一致、13 退化，平均慢 8.32%，平均采样峰值 RSS 增加 3.98%。原替换目标未达到，后续研究已停止。

## 分支实际包含什么

- 将玩家侧多宽度、多策略入口收敛为统一自动搜索；按请求剩余节点、剩余时间及已发现的完整结果安排成员与有限首动作续搜。旧配置仅保留兼容与离线复现用途。调度并非已训练的最优调度策略。
- 同一根和药水政策下复用有界标量搜索证据，完整胜利沿路径回传，只在原 Beam 完全同分时影响排序。共享的是证据；不同成员的搜索前沿、准入决定和转置仍独立，不能称为所有公共路径只搜索一次。
- 提供原始角色、卡牌、费用、能力、遗物状态等上下文观察，以及结果偏好、路线模仿、有界纠偏和离线拟合管线。主排序和选牌可以使用学习模型，但辅助保路、Pareto 等仍消费手写中途估值。
- 保留树模型、稀疏线性/因子、小型神经模型等历史研究入口。最后的 v86 为线性基础加五角色树模型，新增阶段在生长分裂时检查战斗根支持，并将遗物存在条件编译回普通原始特征树；游戏推理无需运行 Python 或训练依赖。
- 包含研究过程中已验证的搜索边界修复、特征采集与分配优化、根来源核对、训练隔离和配对评测工具。分支是研究记录的整体保留，代码与证据较多，不是已完成生产清理的小型补丁。

统一入口会改变分支运行时的搜索行为；“学习模型未启用”不代表整个分支没有运行时变化。最终两臂都经过相同的统一自动协调器，因此本期数据不能单独证明统一入口相对上游旧入口的收益。

## 本期实验边界

模型拟合源码冻结于 `ac201f43`，两臂引擎/宿主来自 `beb18aec`。分支此前合入上游 `8915a7c0`（0.47.0）；准备 PR 时远端上游已到 `72363308`，期间存在较大搜索职责重构。本次只更新比较引用，不合并新源码或启动下一轮回归。**这是冻结实验引擎中旧手写排序与 v86 的比较，不是最新上游版本与本分支的端到端比较，也未证明可以直接合并。**

- 本机：AMD Ryzen 7 7840H，Linux，约 58.6 GiB 物理内存。基准串行固定同四个逻辑 CPU，`DOTNET_PROCESSOR_COUNT=4`，搜索 DOP1。
- 开发集：100 个固定原生解析配置、15 个遭遇家族，五角色各 20 场；普通/精英/首领为 35/35/30。难度分别为进阶 0/5/10，因此类型比较含难度差异。
- 每场 ABBA 或 BAAB，旧算法和候选各两次，合计 400 次独立进程的完整协调器请求；全批运行，不因出现退化停止。
- 相同根戳、实际装备、Beam24、节点 12000、软时间预算 30000ms、手动药水 Disabled、零损早停。软搜索边界不是硬进程总时限。
- 本期训练为 292 根、204,217 条参与观察、700,214 条偏好边。状态行和偏好边高度相关，不能当成独立战斗数。训练/开发/封存集合按原生遭遇家族与近似牌组隔离，同根轨迹及模型祖先不能跨分区。
- 100 场开发集已经反复用于分析与选型，不能冒充独立最终测试。55 个最终配置仍未运行搜索，且仅涵盖 5 个未见普通战家族，不能验证未见精英/首领家族泛化。

质量统计调用既有 C# 终局政策，清零旧 Score。完整政策保留结束回合破同分；核心指标另统一胜利的结束回合，仍比较胜负、复活、战略战损、永久成长、药水等真实目标。两次都不差且至少一次好算改善，两次都相同算一致，两次都不优且至少一次差算退化；方向冲突单列混合，失败/证据不足单列未验证。共同失败也可能是“一致”，不能算作解决战斗。

时间取每场两次请求的算术均值，再汇总；包含根捕获、模型加载和请求收尾，不含此前原生建局及整个进程启动。RSS 是搜索期间每 100ms 采样的整个进程峰值，可能漏掉瞬时尖峰；模型文件大小、托管堆、累计分配与驻留内存分别报告。搜索工作量可不同，不能直接把时间变化归因于模型推理；无头结果不外推 FPS 或可见卡顿。

## 局限性与停止范围

1. 尚未完整去掉手写评分：学习主排序之外，未来能量、抽牌、保留手牌、持续增益等辅助估计仍有人工系数。明确的终局用户政策需要保留，不能靠删掉它来宣称消除启发式。
2. 含遗物/能力输入不等于已经学会组合价值。v86 有 55 个乘积分裂，但包含重复；五角色实际使用玩家能力列合计 22、遗物列 13，NECROBINDER 的玩家能力列仍为 0。特征使用量不是因果重要性或实战质量证明。
3. 根支持约束只限制训练曲率来源的集中程度，不等于统计独立样本数。有限训练根、候选字段与分箱边界仍会漏掉稀少或长期交互。
4. 旧搜索产生的有限续局监督有盲区；训练损失下降、单树条件反转合同、跨语言预测一致均不能保证完整搜索更强。更多同分布随机数据此前也未稳定改善验证排序，尚未定位唯一瓶颈。
5. 本期只验证离线 DOP1、手动药水 Disabled 的固定预算；没有完成多并行度、智能/强制用药、最新上游整合、可见游戏性能及完整生产部署验收。
6. PR 保留源码与聚合证据；完整本地数据、模型产物、游戏依赖、原始日志和 `.local/` 不提交。文档内本地证据路径是来源记录，外部复现需自行准备合法游戏依赖、数据与训练环境，不是拉取仓库即可一键重放全部实验。

本期已结束，停止新增候选、采集、训练与优化；最终集继续封存。不创建发布包或版本标签，不合并 PR。原目标“决策更强，或相同质量明显更快”未达到，不能由工程接线完成代替。

## 如果以后恢复研究，可考虑的改进

以下仅为建议，本次不实施，也没有已验证收益承诺。

- 优先增加有区分力的合法战斗根和可执行替代路线：固定角色/牌组/遭遇做卡牌与遗物的配对干预，覆盖长期铺垫、稀少交互和当前策略从未保留的优质前缀；先测有效根与实际触发覆盖，避免只堆状态行。
- 改善监督与真实搜索目标的对应关系：检查跨回合/不同候选池的排序可比性、教师盲区和首个丢失优质路线的位置；按根平衡而非按重复观察加权，分别验证表示、标签和搜索调度的影响。
- 为替换剩余手写辅助保路设计独立对照：复用同一上下文和价值接口，保留状态等价、合法性及终局政策；逐项验证质量后再讨论删除旧系数，不能一次清零后仅凭速度判好坏。
- 将特征采集、缓存、推理和搜索工作量分开测量；研究增量数值观察、选择列缓存和更紧凑模型，对照固定路线/固定工作量的分配与峰值内存。完整路径共享还需证明状态与政策等价，不能跨成员直接复用剪枝结论。
- 另设不参与调参的最终评估，扩大真实牌组与未见精英/首领家族；预先固定验收标准，报告全部退化及严重胜负翻转。若考虑产品化，应先拆分研究归档与生产候选，再迁移到当时最新上游并验证不同预算、并行度和药水政策。
