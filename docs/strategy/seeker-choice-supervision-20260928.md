# 探寻打击选择风险与有效监督

已修复一个会错误丢弃有效训练见证的问题：探寻打击完成合法选牌后仍被标记为“选择未解析”。这提高了可用监督覆盖，但不是模型已优于旧算法的证据。学习模型继续不默认启用，最终测试仍封存。

## 根因与最小修复

`CardChoiceSupport.BuildSeekerSpec` 在按照分支 RNG 生成三个候选时，无条件追加 `UnresolvedPlayerChoice`。后续唯一动作选择流程实际上会验证给定选择，或在缺少选择时暂停；合法选择完成后，这个累计风险仍保留。`ObserveCompleted` 正确排除有风险的节点，因而同时丢弃了这些已正确模拟的见证。

只删除候选构造处的错误标记。伤害、RNG、候选历史、选择解析、暂停/恢复、续执行与风险聚合的所有权不变；没有清空既有风险，也没有放宽采集或验收门槛。观察仍为8、模型仍为10；原来无风险的观察无需转换，被排除的路径必须重新运行才能取得真实标签。
