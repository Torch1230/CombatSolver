# 交互模型的完整家族留出选型

内部留出实验确认此前弱正则交互模型的泛化明显差于线性基础。加强正则后留出损失接近线性，但唯一选中的完整候选在独立开发仍有两场退化、一场改善，不能替换旧算法。最终测试未打开，用户要求的整体决策质量或同质提速目标仍未达到。

## 隔离与选择规则

复用 v42 的376个经典搜索监督根，原始观察8。按实际遭遇家族划分，NORMAL/WEAK合并；同角色牌组多重集Jaccard≥.85的跨家族根会连接为同一组件，本次没有这种跨家族连接。依照预先固定的哈希种子，在每个章节/遭遇类型中选约四分之一组件作为内部留出；保持各侧原始根顺序。

得到276个内部训练根、100个内部留出根，后者涵盖9个完整遭遇家族。每角色训练47–64根、留出19–23根。内部两侧，以及全部376根与外部开发/最终集之间的模板、原生遭遇、近似牌组审计均通过。

**重新仅用276根拟合线性基础、特征支持度及因子归一化**，不复用此前在376根上学习过的基础项。留出评分由C#读取原始特征，不通过留出侧另行筛选的词表，否则可能错误地删掉稀有但有效的输入。内部留出参与参数选择后就是开发数据，不称为最终测试。

运行前固定六个候选：线性，以及秩8因子的L2=.0001/.001/.01/.1/1；其余优化器、种子和迭代上限沿用前轮。选择一个供所有角色共同使用的配置，依据角色等权、角色内遭遇家族等权、家族内根等权的配对逻辑损失。用既有C#审计的[-40,40]截断边际；精确平局优先线性，再优先更强正则，不根据外部战斗挑选角色头。

## 内部结果

下列准确率将预测平局计半，采用与损失相同的层级平均，既不是全部行的微平均，也不是游戏胜率。

| 候选 | 留出损失 | 留出排序准确率 |
| --- | ---: | ---: |
| 线性 | 0.430664 | 83.4168% |
| L2=.0001 | 5.434016 | 66.4774% |
| L2=.001 | 2.965749 | 68.9831% |
| L2=.01 | 0.874321 | 73.9640% |
| L2=.1 | 0.464563 | 78.3621% |
| L2=1 | 0.427955 | 82.8731% |

规则选中L2=1，但它只略微降低损失，排序准确率还略低于线性。选择冻结后做的探索性家族簇重采样，损失差95%百分位区间为[-.00846,.00186]，跨过零。只有9个家族且已做过选型，不能将这个区间包装成无偏显著性检验，更不能据此宣称游戏变强。

弱正则候选的五个头都达到128次迭代上限，未收敛；L2=1全部收敛。内部基础导出26.77秒，全部六候选选型在143.42秒时完成。诊断与后续外部筛选一起约263.83秒，不将并行背景采集成本混入该壁钟。八项因子Python合同通过，新增验证显式默认值产物一致、强正则参数生效，以及非有限/负参数在创建产物前拒绝；未重复不受影响的C#行为验证。

## 唯一完整候选的实战

选型后用原来的完整376根导出数据重拟合L2=1。只这一候选进入原定外部五场筛选，其余五个配置不逐个打开外部战斗。若选中线性或原L2=.001，协议本来要求复用旧产物与旧验证，不重复运行；本次选中的是新配置。

五角色拟合6.36秒，完整进程6.76秒，峰值RSS691,351,552字节（约0.64 GiB）；所有头收敛。把已发生、未重跑的44.23秒全量导出计入，共50.99秒，低于完整模型1,200秒研究上限。导出历史峰值仍约2.31 GiB，不能只用拟合峰值代表整个准备流程。实际1,280条C#/Python预测零差异。

| BYRDONIS_ELITE | 胜，损28 | 胜，损28 |

两场退化、一场改善，停止于初筛。逐场核对实际装备及两个完整根戳，复用未改变的经典搜索基线。五场进程RSS约329–384 MiB，均有搜索时间边界，不能声称同质量搜索提速。源代码仅新增离线正则化参数及检查，默认仍.001；复用v45同源码主Mod/宿主、两端门禁及五文件部署证据，不启用失败候选。

这次把“训练拟合更好”和“未见场景更好”明确分开。继续增加有效覆盖可能有用，但训练根被分成五份后，每个角色仍只有几十个根。下一步检验跨角色共享统计信息的交互模型；保持这100根留出及外部集身份，不重新挑一个更好看的划分。[结构化证据](factor-regularization-selection-20260928-evidence.json)记录固定协议、分离摘要、完整指标及开发政策结果。
