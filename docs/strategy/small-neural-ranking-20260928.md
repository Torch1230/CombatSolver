# 有界单隐层神经排序器

单隐层模型的训练成本满足要求，但选中的候选仍有2场实战退化，尚不能替换旧算法。Runtime默认和最终测试封存状态均保持不变。

新增可选的16隐单元tanh残差，叠加在原本由战斗偏好学习的线性基础项上。它不读手写卡牌分数，也不在Python重建终局政策。输入沿用原C#权威图、原始观察8和已有角色条件模型；活动列及RMS只取训练侧，输入权重折回原单位。每个完整模型共用一个时限，所有角色和历史导出都计入预算；固定最多128次L-BFGS-B迭代，实际收敛另行记录。

游戏内只增加有界C#数值运算，不依赖Python、PyTorch或ONNX。神经项使用schema11，9/10携带该项、11缺项、混入因子以及非法维度/非有限参数均拒绝。最多32个隐单元，与线性/树共用列裁剪及缓存；参数加载/导出深拷贝，常量残差在空列裁剪后仍可往返。旧格式不序列化空神经字段，线性导出清除全部非线性项并返回schema10。

固定原516根训练、100根家族留出。初轮L2=.001训练内拟合很强，但留出显著退化；完整五角色拟合只用33.03秒，保守加63.81秒历史导出共96.84秒。各头达到128次上限，明确记为未收敛。随后另冻结构不变的.01/.1正则对照，继续原早期成对准确率门槛，整模型选型，不按角色或外部战斗拼接。

四项数学检查通过，梯度有限差分最大误差约5.65e-11；168项C#合同通过，两端结构门禁通过（223个Search文件）。真实初轮神经模型1,280行C#与Python最大差7.11e-15；原树模型在100个已有验证根上的完整审计结果与加入接口前完全相同。首个Release命令编译成功后因沙箱只读而自动复制失败；关闭自动复制后完成构建，保留一次NuGet漏洞元数据网络不可达警告，宿主零错误。没有将复制失败写成已部署。
