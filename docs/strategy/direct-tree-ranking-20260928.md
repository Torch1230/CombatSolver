# 直接树排序与固定线性基础项

去掉已训练的线性基础项后，三个直接树模型的早期和整体留出损失均变差；没有完整重拟合或外部战斗，未启用。此前的实战问题不能简单归因于固定线性项妨碍学习。

原残差训练把C#学到的线性预测作为`base_margin`。它是加在树输出上的固定偏移，语义见[XGBoost官方说明](https://xgboost.readthedocs.io/en/stable/tutorials/intercept.html)；本机依赖仍固定3.4.1。本实验在验证原始导出之后，只将拟合偏移和模型线性权重同时置零，直接优化相同偏好图。不是把基础分用作监督，也没有手写卡牌分数。

固定v54的516根训练、100根遭遇家族留出、深度6及64棵树，只比较叶子Hessian3/1/.3。采集前已冻结的最终集不打开；本轮拟合前声明选型以全部角色的前三回合损失为主，按角色→家族→根等权，仍报告全回合指标，所有角色一起选择。
