# 树叶子证据量约束试验

本轮检验“相关状态很多，但支持某个树叶子的独立战斗可能很少”这一假设。模型明显变小，保住了上一模型漏掉的成长奖励；仍丢失一场旧胜局，也丢失上一模型的一次翻胜，未达到替换门槛。正常游戏与夜间默认拟合均不改变，最终测试未打开。

## 唯一训练改动

复用上一轮已经校验的 376 个训练根、141,734 个抽样行、108,191 个参与行、250,229 对偏好，以及原线性基础、特征支持度与数据顺序。只把 XGBoost 的 `min_child_weight` 从 0 改成 3；64 棵树、深度 6、32 桶、学习率、L2、种子和四线程均保持原值，在运行开发验证前冻结参数。新增离线参数 `--minimum-leaf-hessian`，默认仍为 0，不增加玩家模式。

每个实际根的偏好边权重总和为 1。单边曲率 `h=w*p*(1-p)`，当前优化使用端点各 `2h` 的对角上界，因此一个根贡献的总 Hessian 至多为 `sum(4h)<=sum(w)=1`。分裂后叶子的阈值为 3，就至少需要来自三个根的贡献，无法靠同一场战斗增加相关行数来满足。[官方参数定义](https://xgboost.readthedocs.io/en/stable/parameter.html)说明该门槛按子节点 Hessian 总和执行。

这比直接数根更保守；梯度很小但涉及很多根的叶子仍可能被抑制。它也不保证三个根都有非零净梯度，不能把根的出现直接说成对判断的因果支持。原模型低 Hessian 叶子的数量只说明约束宽松，不足以证明它们各自仅来自一场战斗。

## 验证与结果

八项 Python 检查通过，新增覆盖：一个根的 200 行仍只有一个单位的 Hessian 上限、证据不足不能分裂、足够根权重时仍能学习、非法值拒绝，以及默认参数不变。既有梯度、树导入和数值边界检查同时通过。
