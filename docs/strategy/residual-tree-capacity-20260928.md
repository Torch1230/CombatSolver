# 固定偏好图上的残差树深度对照

浅层树没有胜过深度6对照。补充训练根后的深度6模型改善了留出排序，也保住了第一场旧算法的实质成绩，但仍丢失另一场旧胜局，尚未达到替换要求。

## 固定实验

复用v49的394根训练图、100根完整家族留出及494根完整训练图，不重新采集或导出。同一C#偏好、逐根归一权重、列与线性基础，外部CPU训练器固定64棵树、最小叶子Hessian3，其余参数不变，仅比较深度1/2/3/6。固定脚本在研究副本中设置已有后端参数，不增加生产源码、模型格式或玩家模式。

仍用全部回合的角色→家族→根等权损失选择唯一完整候选；回合分项只是诊断。拟合预算计入历史导出成本，模型还需优于v50稀疏模型的.421734才进入完整重拟合及实战。内部留出不是最终测试，不能将多轮开发选型指标当作未见数据上的无偏成绩。

| 深度 | 留出损失 | 排序准确率 | 五角色拟合进程 |
| --- | ---: | ---: | ---: |
| 1 | .424939 | 82.4257% | 9.26秒 |
| 2 | .418808 | 83.8748% | 10.26秒 |
| 3 | .417248 | 83.9236% | 11.77秒 |
| 6 | .412726 | 84.1223% | 18.02秒 |

各候选加上历史导出44.79秒，完整成本54.05–62.81秒。训练峰值RSS约1.62–1.87GiB。这个结果未支持浅层更好的假设，也表明不能把较小训练集上的模型优劣直接外推到新增数据之后。

## 唯一完整候选与实战

深度6在494根完整图拟合进程24.78秒，加历史导出59.80秒，共84.58秒，拟合峰值RSS约2.13GiB。原C#推理的1,280条实际观察与Python导出预测零差异；XGBoost内部float32累计与导出double累计最大差约1.14e-5，训练对的排序符号没有改变。
