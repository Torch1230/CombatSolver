# 遗物与战斗状态的特征索引复用

本轮将既有编译字段索引从牌堆扩展到角色身份、遗物、Power归属、敌方状态与充能球，减少学习推理中完整字段名的重复构造。完整验证已完成：323项上下文合同、两端结构门禁通过，五场20次同权重对照的完整路线与终局均一致。累计分配降低2.87%，平均耗时仅降低0.45%且三场稍慢，不构成明显提速。v77原冻结100场400次完整评测先正常结束，本轮才开始构建和对照，没有改变其程序、模型或协议。

## 改动范围

`SearchOutcomeContext` 复用 `FeatureScope` 按原路径写入稀疏字典或已选择的数字列；未选择遗物、敌人或充能球类别时跳过该类别。字段名、敌人roster索引、Power汇总顺序与当前分支数值来源保持原定义。未知Power主人继续按原CombatId路径表示，空ID保留原空路径段。

只选敌方动作身份或攻击次数时，不再计算未选择的攻击伤害；只选充能球存在、被动或激发字段时，仅查询实际需要的数值。完整稀疏采集仍读取全部原字段。编译索引只持有名称与列号，未增加跨状态的值缓存，不保留模拟器或卡牌实例。

本轮不修改模型权重、训练图、最终政策、预算、搜索保路或玩家模式。旧快照总分在学习路径已置零，但其余辅助保路仍使用部分手写特征；这次字段读取优化不意味着已经去掉这些启发式。

## 已完成记录中的工作量

只读汇总v76已完成的100场记录，模型转移数合计增加2.68%、耗时增加11.00%。其中61场双方稳定获胜且核心政策相同时，转移数增加4.74%、耗时增加13.23%；进一步限定双方均无时间边界的20场，转移数81,874→102,132，增加24.74%，耗时35.25→44.52秒，增加26.28%。这些合计先对每场每算法的两次记录取均值。

同核心质量不代表同路线、同工作量或同转移类型，以上比例不能拆解出推理器自身的精确成本。它说明需要同时研究排序带来的额外搜索与单次特征读取成本，不能把全部变慢归因于模型计算。本轮继续保持跨回合校准研究，不以字段优化替代决策质量改进。没有新增战斗；原记录摘要与子集身份见 `.local/objective-search/v83/baseline-work-audit.json`。
