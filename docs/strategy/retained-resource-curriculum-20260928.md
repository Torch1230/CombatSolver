# 保留资源与长期能力的匹配补采

组合组略微改善了独立家族留出中的早期排序损失，但没有修复实战的胜利丢失。候选未启用，不能据此认为增加随机数据已经解决问题，也没有同质量提速证据。

## 冻结设计

从v54的516根内部训练侧选择30个不同的亡灵契约师父根，覆盖20个遭遇家族；父根必须由旧算法采集、完整无风险胜利且至少四回合。每对使用相同的新种子、同一张能力牌和相同其余装备。组合组额外加入WISP与DIRGE，对照组对应两槽由原生随机抽取。能力牌为DEMESNE、COUNTDOWN、DANSE_MACABRE，各十对。这些是相关训练兄弟，不能计作独立测试或单牌因果效应。

采集前声明选型指标：同一100根留出中，亡灵契约师较晚端点不超过第三回合的偏好损失，先按根、再按遭遇家族等权。选型只比较基线、组合、随机三组，同时保留原全回合指标。这是针对早期资源决策的开发实验，最终测试仍封存。未把外部失败战斗的轨迹作为训练标签。

60场原生建局与采集全部完成，墙钟283.55秒，无隔离失败；组合组23场、随机组24场有有效偏好。只使用双方都有效的20对，得到每组536根内部训练、636根完整训练。原始摘要、完整根戳、实际装备、遭遇家族及近牌组隔离均检查；相同父根的所有派生轨迹保持在训练侧。

## 结果

固定深度6、64棵树和叶子Hessian3，不同时调整模型容量。早期指标涵盖8家族、19根、2,174对。

| 组 | 早期损失 | 早期准确率 | 全回合损失 |
| --- | ---: | ---: | ---: |
| 原基线 | .574419 | 72.3037% | .410549 |
| 组合 | .573511 | 71.7968% | .409365 |
| 随机 | .587960 | 68.7997% | .412213 |

按预定损失选中组合组；准确率没有一起提高。唯一636根完整模型导出81.82秒、拟合28.04秒，合计109.86秒，拟合峰值RSS约3.34GiB。其他四角色的内部及完整模型文档均与对应基线完全相同；1,280条实际观察的C#/Python预测零差异。

五场固定外部开发战斗中，KAISER_CRAB_BOSS仍从旧算法胜利损64退化为失败损66，剩余敌人HP112；其他四场实质终局政策相同。一场退化、没有改善，未进入另外十场开发或最终测试。拟合与评测研究383.24秒，另计前述采集成本。
