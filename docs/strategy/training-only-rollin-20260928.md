# 训练侧模型轨迹与匹配旧策略对照

模型轨迹补查增加了有效结局见证，但其留出结果没有优于旧策略重采对照。按预定规则选中的旧策略增补候选在实战中一场改善、两场退化，未启用。新增纠正标签本身不能作为模型更强的证明。

## 隔离与配对

从v54的516根内部训练侧选60个旧策略无风险胜利且至少四回合的父根，每角色12个，按遭遇均衡和固定摘要顺序选择。同一父根分别用旧策略及固定的内部516根模型搜索；两臂都保持12秒、6,000节点、Beam16及DOP1。每次核对实际装备、原始数据摘要和两个完整根戳。

生成模型轨迹的教师只拟合内部516根，未拟合100根选型留出的行。其完整输入谱系再次与内部留出、15根外部开发及封存最终五根检查家族和近牌组隔离；没有直接采用夜间任务中可能包含内部留出祖先的模型轨迹。所有来源属于原训练根，同根多策略文件由既有C#宿主统一重映射组号、抽样和分配一次根权重。

每条模型轨迹沿既有离线纠正入口，对至多三个动作深度的保留/淘汰前缀补做有界旧Beam续搜，总额外预算六秒。未知仍未知；完整死亡只说明找到一个失败后缀，不把整个活状态判作无解。这个实验检验模型访问分布上的有界纠正，不声称实现完整DAgger或继承其理论保证；分布偏移背景见[原论文](https://proceedings.mlr.press/v15/ross11a.html)。

## 数据与故障记录

120次搜索全部成功，采集墙钟521.31秒，子进程耗时合计2,023.09秒。模型组30,646行、59根有偏好，旧策略组32,546行、57根有偏好；双方都有效的56对进入拟合，训练/完整根数仍是516/616。没有把相关轨迹计作新独立战斗。

208次补查中，132次把未知补到胜利后缀，21次补到真实死亡后缀，7次从已知失败后缀补到胜利，28次改善已有胜利见证；18次保留原见证，2次仍未知。两臂的抽样和池覆盖也可能变化，因此只比较完整增补流程，不能把差异全部归因于纠正本身。

原汇总脚本错误地要求旧策略组也存在仅模型组生成的纠正诊断文件。主流程等待所有子进程完成后报告失败；后续只恢复汇总，逐个检查退出码0、M2完成、原始标签、装备和根戳，未重跑成功搜索。保留原异常、原单场记录及单独恢复记录；没有游戏失败被改判成功。只读分类诊断另修正了一处字段大小写，不修改数据。

采集前固定深度6、64棵树、叶子Hessian3、每根512行。候选必须降低原全回合等角色/家族/根损失，同时前三回合损失不变差；符合者只选一个完整重拟合。

选中旧策略组。完整616根导出83.58秒、拟合30.04秒；保守计入生成模型轨迹的祖先拟合85.83秒后，共199.45秒。拟合峰值RSS约3.34GiB，1,280条C#/Python实际观察预测零差异。

五场固定开发中，KNOWLEDGE_DEMON_BOSS由旧失败损75变为胜利损70；THE_KIN_BOSS由胜利损24变为损29，两者均有一次成长；KAISER_CRAB_BOSS仍由旧胜利损64变为失败损66。其余两场实质政策相同。一场改善、两场退化，未扩展开发、未打开最终测试。拟合及评测阶段410.94秒，采集成本另列。
