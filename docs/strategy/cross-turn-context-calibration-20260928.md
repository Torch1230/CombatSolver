# 同根跨回合完成见证校准

训练上下文审计发现，原模型在同根、跨回合且没有共享候选池的完成见证上仍有排序误差。本轮增加一个显式离线实验：复用已有结果观察，为这些上下文补充有限的严格终局政策比较。v77采集、训练和完整评测继续使用原冻结产物，本轮没有回写其协议或模型。

## 训练图的变化

联合输入可显式增加 `crossTurnOutcomes: true`，要求同时使用已有 `balanceCorrectionSources: true` 和逐根对齐的纠偏输入。该开关只存在于离线导出，不增加玩家模式，也不改变模型格式、推理器或实际搜索预算。

`SearchOutcomeValueModel.ContextTraining` 从每个原物理根的结果观察中抽样至多256行，使用与原图抽样及战斗RNG分开的固定随机流。全部原始结果行的正整数回合在首轮读入抽样前验证，二次抽样前也校验全部合格观察。模仿行和纠偏行不用于构造新增比较；新比较直接引用原行，不复制特征字典或制造新物理根。

只有两个条件同时满足才考虑新增比较：端点处于不同回合，且不共享原候选池。比较共用 `CompareWitnesses` 的胜负与完整胜局政策，双方均败、最终政策相同、仅剩余动作长度不同的对均跳过。失败后缀依然只是观察到的结果，不能证明该状态必败；模型并未获得最优状态值标签。

每根最多考察32,640个无序对，在真实合格偏好中蓄水池抽取至多1,024对。新增边和原边共用去重与每根4,096对总额度；全部有效纠偏边继续保留，剩余空间分配原联合监督。开启实验会使饱和根让出部分原边，不声称原图所有边不变。

普通联合监督、纠偏、跨回合比较这三个**非空来源**等分该根总权重，整根仍为1。三来源均有效时各占1/3；只有两来源有效时各占1/2。增加来源也会改变原来源的相对权重，因此这是“增加比较并按来源平衡”的整体实验，不能单独归因于新增边数量；等权不代表三者置信度相同或已证实最优。特征支持度仍按独立物理根计数。

## 已完成验证

- 主Mod与宿主Release构建通过；主构建只有离线NuGet漏洞信息源警告。Bash/PowerShell结构门禁各231个Search文件通过。
- 235项排序/训练合同通过，含新增22项：原行复用、跨目标/根隔离、政策平局、全败局无信号、缺失/非法回合、4,096总边与1,024新增边上限、纠偏保留、根/来源权重、稀有特征支持和固定随机流的可重复性。
- 沿用原十训练根、五角色各两个。关闭新开关时，五角色基础模型JSON和15份观察矩阵/边/基础分二进制与v76原导出完全一致；新元数据仅增加零值的跨回合计数与权重。

- Python输出文档与C#在1,280行预测上的最大绝对差为0。最终源码已完成本地规定的五文件部署，学习模型继续关闭。

## 完整候选协议
