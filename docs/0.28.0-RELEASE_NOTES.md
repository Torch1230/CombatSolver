# Combat Solver v0.28.0 更好的小循环、无限与跨回合决策

- 求解器现在能更好地识别小循环、无限与接近无限的资源闭环，也会为循环启动保留必要的铺垫路线。
- 跨回合收益会综合过牌、回收、能量、星能、持久成长、延迟伤害与特殊战斗目标，需要多个回合兑现的组合更容易被找到。
- 卖血决策会同时比较实际战损与后续收益：值得的生命投资可以换取更强的循环或更优终局，低损路线也不会被更快但掉血更多的路线覆盖。

感谢 [洛天琉璃依（@ltlly）](https://github.com/ltlly) 在 [PR #35](https://github.com/Torch1230/CombatSolver/pull/35) 中贡献本次核心实现。
