# 预测卡牌引用与集合状态辅助接口

`PredictionCardReferences` 按原卡或当前 Preview 的对象身份解析分支卡牌，并通过同一个 Fork context 重映射引用列表。状态 writer 按玩家、牌堆和位置描述引用，保留空值、重复元素及顺序；仅显式无序集合进行排序。

缺失、歧义、外分支及已移出战斗牌堆的引用明确失败。同名卡牌不会仅按 ID 合并，也不建立全局对象 ID 或自动复制任意对象图。

引用索引每次观察按需建立并跨模型共享；标量和空引用路径不建立索引。接口不扩展战斗中途获得或移除遗物的生命周期。

合同检查、完整模拟器 Fork、Preview COW、T1→T2 原生对账及第 2 回合精确续用通过。接口用法见[模型状态适配](../third-party-model-state.md#卡牌引用辅助接口)，验证范围见[测试清单](../TEST_MATRIX.md)。
