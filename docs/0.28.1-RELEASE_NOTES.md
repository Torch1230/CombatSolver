# Combat Solver v0.28.1 药水策略与系统内存释放

- 修复 Smart 药水策略过于积极的问题。普通战斗中，每瓶付费药仍需至少节省 `9 HP`；第一、二幕末会按战后回复折算为 `45 HP`。无药已经能够获胜时，不再仅为缩短回合而交药。
- 用药梯度重新按照无药战损限制搜索层数，并在第一档满足收益门槛后停止，减少没有实际收益的多药搜索。
- 动态路线展示同步计算药水成本，未省足生命的用药路线不会覆盖当前无药路线。
- 主界面内存预览条右侧新增“强制释放内存”按钮。点击后会等待搜索退出，随后请求 Windows 管理员权限，释放求解器内存并清理系统工作集与待机列表。

系统内存释放可能使其他程序在重新载入页面时短暂卡顿，只会在玩家主动点击后执行。
