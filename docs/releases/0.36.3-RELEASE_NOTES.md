# 0.36.3

## 简体中文

- 策略信息放在血量左侧并右对齐，放大字号；成功标绿、未达标标黄，同时显示目标和实际计数。删除重复标题。全自动按钮关闭时灰色，开启时绿色。

- 路线摘要新增策略结果：显示预计已卡好的遗物、未达标的遗物及各自结束计数，以及已触发的成长收益和次数。
- 未完成的搜索显示当前进度，避免把中途达到的计数误认为战斗结束时已经达标。

## English

- Strategy results are right-aligned immediately before HP, with larger text, green successes and yellow unmet targets showing target and actual counts. Removed redundant headings. Auto-play is gray when off and green when on.

- Route summaries now show aligned and unmet relic targets with their projected ending counter values, and growth rewards with trigger counts.
- Incomplete routes display current progress instead of claiming that intermediate counters are final combat results.
