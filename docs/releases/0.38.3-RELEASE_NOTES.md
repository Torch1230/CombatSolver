# CombatSolver 0.38.3

## 简体中文

- 药水侧栏新增“全部智能”“全部保护”“全部强制”“仅用已强制”四个批量预设。批量操作只影响当前可搜索的药水，不会改动不可搜索的药水。
- 新增固定快捷键 `Ctrl+F9`，可在单人战斗中显示或隐藏整个求解器界面。隐藏界面不会停止搜索、路线执行或全自动，恢复后继续保留当前路线与界面状态。
- 修复问题包上传弹窗的正文和描述输入框不显示的问题。弹窗现在保持标题和按钮可见，正文可滚动，并会随游戏窗口大小调整和约束位置。
- 修复工具箱等原生选牌界面被卡组页面临时遮挡超过 30 秒后，求解器误判选牌已经中断的问题。关闭卡组后会继续等待原来的选择，不会取消搜索或改变全自动状态。
- 优化成长目标的搜索停止判断。能力牌、消耗牌和固定重复出牌现在按本场实际可兑现的次数计算；存在动态重复出牌、复制或回收时继续完整搜索，避免过早结束。已经能够证明全部成长机会兑现时则及时停止，减少无效搜索。
- 取消搜索层失败后的缩小范围二次尝试。求解器现在保留玩家所选搜索强度，避免把剩余时间用于质量较差的窄范围补搜；完全没有找到生还路线时的扩大重搜仍然保留。

## English

- Added four batch presets to the potion sidebar: “All smart,” “Protect all,” “Force all,” and “Forced only.” Batch changes affect only potions currently available to the search and leave unavailable potions unchanged.
- Added the fixed `Ctrl+F9` shortcut to show or hide the entire solver overlay during single-player combat. Hiding the overlay does not stop searching, route execution, or full automation, and restoring it preserves the current route and UI state.
- Fixed the issue report upload dialog sometimes hiding its body and description field. The title and action buttons now remain visible, the body scrolls when needed, and the dialog stays within the game window as its size changes.
- Fixed the solver treating a native card choice as interrupted when the deck screen temporarily covered it for more than 30 seconds, including choices from Tools of the Trade. Closing the deck now resumes the original choice without cancelling the search or changing full automation.
- Improved search stopping for permanent growth goals. Power cards, exhaust cards, and fixed replay effects are counted by the number of rewards that can actually be obtained in the current combat. Searches continue when dynamic replays, copies, or recovery make the limit uncertain, preventing premature stops; they stop promptly once every provable opportunity has been completed.
- Removed the reduced-scope retry after an individual search layer fails. The solver now keeps the search strength selected by the player instead of spending the remaining time on a lower-quality narrow retry. The broader retry used when no survivable route is found remains available.
