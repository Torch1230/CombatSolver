# CombatSolver 0.38.2

## 简体中文

- 为第三方 Mod 提供新的战斗适配接口，覆盖回合结束后的晚期结算和能量重置后的能力触发。
- 支持第三方效果安全记录并恢复具体卡牌实例引用，使跨回合路线能够识别同名卡牌的不同实例。
- 支持按游戏中的实际补丁组合模拟卡牌出牌效果，减少已适配第三方 Mod 与路线预测之间的不一致。

这些能力需要第三方 Mod 主动接入新接口后生效。CombatSolver 当前没有内置第三方适配声明；原版战斗规则、搜索预算和路线排序保持不变。

## English

- Added combat integration APIs for third-party mods, covering late end-of-turn resolution and effects triggered after energy resets.
- Added safe recording and restoration of references to specific card instances, allowing multi-turn routes to distinguish between separate copies of the same card.
- Added support for simulating card play effects using the game's actual registered patch composition, reducing prediction differences for integrated third-party mods.

Third-party mods must adopt the new APIs before these capabilities take effect. CombatSolver currently ships without built-in third-party integration declarations; vanilla combat rules, search budgets, and route ordering are unchanged.
