# CombatSolver 0.45.0

## 简体中文

- 感谢 [s1f102500012](https://github.com/s1f102500012) 提交的 [PR #130](https://github.com/Torch1230/CombatSolver/pull/130)：搜索时“已查阅世界线”数量会逐渐滚动到最新值，不再随进度报告突然跳变，更容易看清路线搜索的推进。
- 感谢 [s1f102500012](https://github.com/s1f102500012) 提交的 [PR #130](https://github.com/Torch1230/CombatSolver/pull/130)：内存条、已用时间和搜索进度条现在平滑过渡；内存整理时有轻微动态提示。自动执行路线时，当前动作高亮随出牌节奏变化，问题包上传进度条也更平顺。
- 修复求解器窗口位置偶尔无法保留的问题。拖动后，下场战斗和重启游戏会使用保存的位置；窗口临时缩小时，恢复尺寸后也会回到原位置。

## English

- [PR #130](https://github.com/Torch1230/CombatSolver/pull/130) by [s1f102500012](https://github.com/s1f102500012): The reviewed-worldline count now rolls smoothly toward each search update instead of jumping, making search progress easier to follow.
- [PR #130](https://github.com/Torch1230/CombatSolver/pull/130) by [s1f102500012](https://github.com/s1f102500012): The memory bar, elapsed time, and search progress bar now transition smoothly, with a subtle activity cue during memory cleanup. Action highlights follow the pace of auto-play, and bug report upload progress is smoother.
- Fixed the solver overlay occasionally losing its position. Its saved position now carries over to the next combat and after restarting the game, and returns when a temporarily smaller window is restored.
