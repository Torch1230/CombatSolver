# CombatSolver 0.37.0：性能更新 / Performance Update

## 简体中文

本次更新主要优化复杂战斗的求解性能，并修正部分战斗效果的预测。

- 减少大量选牌、生成卡牌、使用药水和跨回合推演时的重复计算与临时内存开销。
- 优化多核并行求解，减少部分出牌、状态效果和回合结束推演之间的等待。
- 改善较低搜索内存设置下的任务安排，减少内存预留过大造成的并行受限。
- 修正部分格挡、临时力量和持续减益效果的预测，改善效果叠加和跨回合持续时间的判断。
- 保持原有搜索预算与路线评价规则。

具体收益因战斗、硬件和 Mod 组合而异，部分场景仍可能耗时更长；本次不承诺统一的加速比例或帧率提升。

感谢 [ltlly](https://github.com/ltlly) 在 [PR #89](https://github.com/Torch1230/CombatSolver/pull/89) 中贡献性能优化与预测修复，并提供详细的验证和实验记录。

## English

This update focuses on solver performance in complex fights and corrects predictions for several combat effects.

- Reduced repeated calculations and temporary memory use when evaluating large card selections, card generation, potion use, and future turns.
- Improved multicore scheduling to reduce waiting between some card, status-effect, and end-of-turn simulations.
- Improved task scheduling with lower search memory settings, reducing limits on parallel work caused by excessive memory reservations.
- Corrected predictions for some block, temporary Strength, and timed debuff effects, including stacking and duration across turns.
- Preserved existing search budgets and route evaluation rules.

Gains vary by fight, hardware, and Mod combination, and some scenarios may still take longer. This update does not promise a uniform speedup or an FPS increase.

Thanks to [ltlly](https://github.com/ltlly) for the performance improvements and prediction fixes in [PR #89](https://github.com/Torch1230/CombatSolver/pull/89), along with detailed validation and experiment records.
