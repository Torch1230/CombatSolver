# CombatSolver 0.34.8

## 简体中文

- 修复天际钻头在 X 达到翻倍条件时少算攻击次数的问题，包含化学物X带来的加成，修正相关击杀和复活后的战损预测。
- 修复末日降临与血肉戏法配合时的击杀判断顺序，正确计入触发伤害，避免预测敌人多行动一次。
- 修复夜魇复制的卡牌状态、既定事项的取牌顺序，以及剑圣对君王之剑复制牌的重复打出次数预测。
- 修复神气制胜多次获得、临时力量／敏捷／集中、暗淡蓝点已经触发后重新计算时的效果预测。
- 修复历史课与怀旧的回合记录，以及不休陀螺、冰雹风暴、黑暗之拥与音乐盒相关的回合结束抽牌和结算顺序，减少路线执行中断和计划外重算。
- 修复部分附魔卡牌在计算过程中引发异常的问题。
- 检测到已知不兼容的 PengoTarot、BetterCharacterRelics 或 WheelchairSpire 时，直接显示对应 Mod 名称和不兼容原因；这类问题不会引导上传日志。

## English

- Fixed Heavenly Drill undercounting hits when X reaches its doubling threshold, including the bonus from Chemical X. This corrects related kill timing and predicted HP loss after enemy revival.
- Fixed the kill check order for End of Days with Sleight of Flesh so triggered damage is included before evaluating lethal, avoiding an incorrectly predicted extra enemy action.
- Fixed copied card state for Nightmare, card retrieval order for Foregone Conclusion, and Sword Sage's replay count on copies of Sovereign Blade.
- Fixed effect predictions for multiple instances of Panache, temporary Strength / Dexterity / Focus, and recalculation after Pale Blue Dot has already triggered.
- Fixed turn history for History Course and Nostalgia, plus end-of-turn draws and effect order involving Unceasing Top, Hailstorm, Dark Embrace, and Music Box, reducing interrupted execution and unexpected replanning.
- Fixed errors caused by some enchanted cards during calculation.
- Known incompatibilities with PengoTarot, BetterCharacterRelics, or WheelchairSpire now show the Mod name and reason directly. These errors do not prompt players to upload logs.
