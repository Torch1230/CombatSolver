# CombatSolver 0.51.4

## 简体中文

- 修复大树将倾击杀后的群体伤害预测，解决相关战斗重算和路线回放失败。
- 修复旧角色获得射箭牌后漏算箭槽的问题，改善跨回合路线续用。
- 修复射箭触发洪流巨人转阶段时，插箭、虚弱和易伤被预测清除的问题。
- 修复横祸在抽牌堆为空时的随机序列偏差，避免影响后续随机结果与路线续用。
- 修复安可与探寻打击等选牌效果组合时的计算失败，补齐选牌续接中的伤害历史。
- 修复智能药水尝试双药方案失败时中断整次计算的问题，保留已有路线。

## English

- Fixed Timber's splash damage prediction after a kill, resolving related recalculations and route replay failures.
- Fixed missing arrow slots when other characters obtain Shoot cards, improving route continuation across turns.
- Fixed predictions clearing Impaled, Weak and Vulnerable when an arrow triggers Waterfall Giant's phase transition.
- Fixed Catastrophe's RNG consumption with an empty draw pile, preserving subsequent random outcomes and route continuation.
- Fixed calculation failures when Encore interacts with card selection effects such as Seeker Strike, and preserved damage history during selection continuation.
- Fixed optional two-potion searches aborting the entire Smart potion calculation when they find no qualifying route, preserving the existing plan.
