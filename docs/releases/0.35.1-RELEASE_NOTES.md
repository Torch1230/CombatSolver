# CombatSolver 0.35.1

## 简体中文

- 修复 Windows 下自动内存管理过早、频繁整理内存的问题：正确利用已经释放的空间，避免在仍有余量时反复打断搜索。
- 内存压力根据实时物理占用判断，继续遵守配置的预算和安全上限。

## English

- Fixed automatic memory management reclaiming memory too early and too often on Windows. Reclaimed space is now accounted for correctly, avoiding repeated search interruptions while capacity remains.
- Memory pressure now follows current physical usage while retaining the configured budget and safety limits.
