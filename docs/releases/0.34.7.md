# 0.34.7

## 简体中文

- 在线统计新增跑局胜负、放弃、胜率、当前连胜与最高连胜，区分全程开启求解器、部分参与及未参与。
- 已有游戏战绩作为独立历史参考，新记录的求解器战绩从更新后开始累计。
- 断线后补传，续档沿用同一局；问题包附带提交时的战绩，方便作者按连胜等条件排查反馈。
- 设置中的在线统计说明同步更新中英文，关闭后停止自动战绩上传。

## English

- Online statistics now track run wins, losses, abandonments, win rate, and current/best streaks, with separate categories for full, partial, and no solver participation.
- Existing game statistics remain a separate historical reference. Solver statistics begin with runs tracked after this update.
- Pending results sync after reconnecting, and continued saves keep the same run identity. Bug reports include a statistics snapshot from submission time.
- Updated the statistics setting in Chinese and English. Turning it off stops automatic result uploads.
