# CombatSolver 0.34.9

## 简体中文

- 新增战斗搜索目标：平衡、保命优先、永久培养优先、净收益优先，可在成长策略面板中选择。
- 永久培养与净收益目标可设置累计战损上限、最低结束血量和目标值。默认分别为 3 点成长、25 分净收益；找到达标、完整获胜且满足血量限制的路线后停止继续搜索。每次重新搜索重新计量。
- 全自动遇到尚未确认完整胜利、或未满足收益血量限制的路线时，显示具体暂停原因和数值。
- 改善小刀生成与力量多段攻击的配合估值，更准确地考虑铺垫所需的出牌次数和一次性效果。
- 改善黑暗之拥相关的消耗抽牌估值，考虑腐化、不可抽牌与虚无在回合结束时的结算顺序。
- 复用未变化牌堆的状态计算，减少搜索中的重复工作。

## English

- Added combat search objectives: Balanced, Survival, Permanent Growth, and Net Resources, selectable in the Growth Strategy panel.
- Growth and resource objectives support limits on total battle HP loss, minimum ending HP, and a target value. Defaults are 3 growth points and 25 net-resource points. Search stops once it finds a complete victory that reaches the target within the HP limits. Each new search starts a new measurement.
- Auto-play now shows the specific reason and values when it pauses because a complete victory has not been confirmed or a reward route exceeds the HP limits.
- Improved estimates for Shiv generation and multi-hit attacks with Strength, accounting for setup actions and single-use effects.
- Improved Dark Embrace exhaust-draw estimates, including Corruption, No Draw, and Ethereal end-of-turn timing.
- Reused state calculations for unchanged card piles to reduce repeated search work.
