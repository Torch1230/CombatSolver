# CombatSolver 0.50.1

## 简体中文

- 修复智能药水在收益不足时仍使用药水的问题，避免为了少掉一点血消耗多瓶药水。继续优化路线时也会综合考虑省血收益与药水价值，保留必要保命、强制使用和战后补充药水的抵扣。
- 感谢 [shun-tong](https://github.com/shun-tong) 提交的 [PR #213](https://github.com/Torch1230/CombatSolver/pull/213)：改善长战斗中能力牌和药水的使用路线，强制用药后也能从仍可行动的回合继续寻找更好的路线。
- 感谢 [link20031019](https://github.com/link20031019) 提交的 [PR #226](https://github.com/Torch1230/CombatSolver/pull/226)：Ctrl+F9 隐藏面板后，界面刷新和进入下一场战斗会保持隐藏，再次按键恢复显示；重启游戏后恢复默认显示状态。
- 感谢 [tianyilt](https://github.com/tianyilt) 提交的 [PR #224](https://github.com/Torch1230/CombatSolver/pull/224)：提高改变手牌上限后的路线复用准确性。

## English

- Fixed Smart potion choices spending potions for insufficient benefit, including using multiple potions to save very little HP. Continued route optimization now weighs HP savings against potion value, while preserving necessary survival uses, Force directives, and replacement credit for post-combat potion rewards.
- [PR #213](https://github.com/Torch1230/CombatSolver/pull/213) by [shun-tong](https://github.com/shun-tong): Improved routes involving powers and potions in long battles. Searches can continue from playable turn boundaries after forced potion use to find better routes.
- [PR #226](https://github.com/Torch1230/CombatSolver/pull/226) by [link20031019](https://github.com/link20031019): Panels hidden with Ctrl+F9 stay hidden across UI refreshes and subsequent battles. Press the shortcut again to show them; restarting the game restores the default visibility.
- [PR #224](https://github.com/Torch1230/CombatSolver/pull/224) by [tianyilt](https://github.com/tianyilt): Improved route reuse accuracy after changes to the hand-size limit.
