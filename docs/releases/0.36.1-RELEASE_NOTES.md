# 0.36.1

## 简体中文

- 重新整理遗物、成长和药水面板：实色背景、更大更清楚的文字、更宽松的控件间距。遗物加入游戏原生图标，优先显示已持有项；药水策略直接显示完整名称。

- 新增“遗物”策略面板，与“药水”“成长”并列。支持为十种可跨战斗保留、能靠战斗内行动调整的计数设置目标范围和愿意支付的额外战损。
- 提供默认开启的总开关和每个遗物默认关闭的独立开关；关闭后保留配置。只对当前持有的遗物生效，其他计数遗物会说明不能参与卡数的原因。
- 计数达标后继续沿用原战损、成长和药水条件早停；没有生效的遗物目标时保持原早停行为。每项血量额度只计算一次，不会因反复触发而累加。
- 修复部分带前置资源牌或药水的补充路线在回放时遗漏前置动作的问题。

## English

- Redesigned Relics, Growth and Potions with opaque backgrounds, larger text and more spacing. Relics now use native game icons and prioritize owned items; potion controls display their full policy names.

- Added a Relics strategy panel beside Potions and Growth. Set target ranges and extra HP-loss allowances for ten counters that persist between combats and can be influenced by combat actions.
- Includes a master switch enabled by default and individual switches that default to off. Disabling them preserves your settings. Only owned relics affect planning; other counters explain why they are not targeted.
- Once counter targets are met, the existing HP-loss, growth and potion conditions still allow early stopping. Searches with no active relic targets retain their original stopping behavior. Each relic's allowance is counted once, never repeatedly accumulated.
- Fixed missing prefix actions when replaying some supplemental routes that begin with resource cards or potions.
