# CombatSolver 0.51.3

## 简体中文

- 修复不安油灯对同一张牌施加的多种减益只预测首种翻倍的问题，改善易伤持续时间与后续路线续用。
- 自动执行时若游戏中的出牌或药水结算报错，立即暂停后续执行，并在问题报告中保留原始异常，便于定位。
- 修复恐惧模式下乐加维林族母削减力量与敏捷的预测偏差，避免后续回合因属性不一致而重算。
- 修复疑虑和羞耻在回合结束时施加的虚弱／脆弱被预测为提前消失的问题，改善跨回合路线续用与战损预测。
- 修复恐惧模式下打断仪式兽犁击时遗漏仪式及后续力量增长的预测问题。

## English

- Fixed Unsettling Lamp predictions doubling only the first of multiple debuffs applied by the same card, improving Vulnerable duration and route continuation.
- Automated execution now pauses immediately if a card or potion action fails in the game, preserving the original exception in the issue report for diagnosis.
- Fixed predictions for Strength and Dexterity loss from Lagavulin Matriarch in Dread mode, preventing recalculation caused by mismatched stats on later turns.
- Fixed debuffs applied by Doubt and Shame at turn end expiring too early in predictions, improving route continuation and projected HP loss across turns.
- Fixed missing Ritual and subsequent Strength gains in predictions when interrupting Ceremonial Beast's Plow in Dread mode.
