# CombatSolver 0.46.6

## 简体中文

- Loadout 2 更新后，只要怪物额外能力接口仍可读取且未配置怪物额外能力，求解器就能正常搜索，不再因 Loadout 版本号变化而停用。

## English

- Combat search now checks Loadout 2's loaded monster power interface and configuration instead of its version number. Updates that keep the interface and leave extra monster powers unconfigured remain compatible.
