# 0.35.3

## 简体中文

- 新增版本更新横幅：在线统计开启时，随心跳向监控服务检查最新版本，发现当前版本较旧便提醒更新，无需连接创意工坊检查版本。
- 修复部分回合末失血漏算、预计战损与路线回放不一致的问题。
- 修复搜索达到预算限制、结束回合收尾时可能中断计算的问题。
- 修复部分攻击在单体与群体目标之间判断错误、导致搜索失败的问题。
- 修复预测中死亡后的伤害与能力清理顺序，避免不应发生的伤害和连锁效果。

感谢 **ZacharyZcR** 提交 PR #78–#82，为这批战斗预测与搜索修复作出贡献！

## English

- Added an update banner: when online statistics are enabled, heartbeats check the monitoring service for the latest version and notify outdated clients, without contacting the Steam Workshop for version checks.
- Fixed cases where end-of-turn HP loss was missed, causing projected damage and route replay to disagree.
- Fixed searches failing while wrapping up a turn after reaching their budget limits.
- Fixed incorrect single-target versus all-enemy targeting for certain attacks, which could interrupt a search.
- Fixed predicted damage and power cleanup after death, preventing damage and follow-up effects that should not occur.

Thanks to **ZacharyZcR** for contributing PRs #78–#82 and these combat prediction and search fixes!
