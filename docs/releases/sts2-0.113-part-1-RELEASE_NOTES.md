# CombatSolver · 0.113 适配 Part 1

## 简体中文

本次更新适配《杀戮尖塔 2》v0.113.0 Beta 的单人标准模式。

- 新增愚者的战斗路线求解，支持箭槽、射箭、插箭、拔箭回收与旋律组合，以及相关卡牌、遗物和药水。
- 同步五位原有角色及通用战斗内容的新版调整，更新卡牌费用、伤害、升级效果、自动出牌、保留手牌、额外回合和怪物行动等结算。
- 适配新版随机规则，让随机选牌、卡牌转变、自动出牌和药水生成按新版游戏规则参与路线计算。
- 愚者路线支持单步执行、自动执行和跨回合续用，持续效果、箭的状态与旋律记录随战斗推进。
- 成长策略新增「炫技」，可设置为了永久强化卡牌愿意承受的战损。
- 搜索详情显示整次计算的累计节点数；节点和时间上限提示按本次搜索预算显示，路线续用与缓存恢复显示实际计算情况。

**下一阶段：0.113 适配 Part 2，计划适配恐惧和极速模式。**

## English

This update adapts CombatSolver to single-player Standard mode in Slay the Spire 2 v0.113.0 Beta.

- Added combat route solving for the Fool, including arrow slots, shooting, impaling, dislodging and retrieving arrows, melody combinations, and the related cards, relics, and potions.
- Updated support for balance and gameplay changes affecting the five existing characters and shared combat content, including card costs, damage, upgrades, auto-play, retained cards, extra turns, and monster actions.
- Updated random selection, card transformations, auto-play, and potion generation to follow the new game's random rules during route calculation.
- Fool routes support step-by-step execution, automatic execution, and continuation across turns, carrying persistent effects, arrow states, and melody history through combat.
- Added Show Off to growth strategies, allowing you to set how much HP you are willing to spend for its permanent card improvement.
- Search details now show the total nodes explored across the whole calculation. Node and time limit notices reflect the current search budget, while route continuation and cached routes show the work performed for the current request.

**Next: 0.113 Adaptation Part 2, with support planned for Dread and Blitz modes.**
