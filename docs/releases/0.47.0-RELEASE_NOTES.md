# CombatSolver 0.47.0

## 策略优化 Part 1

我们炼化了 101 个更优世界线包！

## 简体中文

- 优化能力牌、升级牌与成长路线，更好地保留跨回合收益。
- 优化药水的使用时机、生成选项和机会成本。
- 优化抽牌、弃牌、零费牌与多目标转火的配合。
- 改善早期回合的路线保留，并新增默认关闭的“前两回合深入探索（实验）”开关。
- 修复部分组合出牌、选牌和回合结束动作导致的搜索失败。

## English

We worked through 101 better-worldline reports!

- Improved Power, upgrade and scaling routes by retaining more cross-turn value.
- Improved potion timing, generated choices and opportunity costs.
- Improved interactions among draw, discard, free cards and target switching.
- Preserved more early-turn routes and added Deep Early-turn Exploration as an experimental setting, off by default.
- Fixed search failures involving combined card plays, choices and turn-ending actions.
