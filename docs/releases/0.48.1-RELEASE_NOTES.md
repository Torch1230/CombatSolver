# CombatSolver 0.48.1

## 简体中文

相对于 0.48.0 的更新：

- 修正手动喝药后的“更优世界线”误判：每额外使用一瓶药，预计整场战损至少下降 9 HP 才会提示；原路线已经计划使用的药不会重复计入成本。
- 问题反馈、日志和日志后台新增用药比较信息，显示比原路线多用了几瓶药，以及扣除药水成本后的战损改善量。后台支持按折算后的改善量筛选和排序，批量导出也包含这些信息；旧报告缺少用药信息时标为未知。
- 修复倾泻配合无尽陀螺时的抽牌时机预测错误，减少由此导致的选牌错误和路线执行中止。
- 修复金纸配合生成牌时，回合末消耗的预测与实际结果不一致的问题。
- 修复压缩生成燃料时，预测手牌顺序与实际结果不一致的问题；修复子弹时间后部分卡牌星能费用的预测错误，减少由此触发的计划外重算。

## English

Changes since 0.48.0:

- Corrected false “better worldline” feedback after manual potion use: each additional potion must save at least 9 projected HP over the entire fight. Potions already planned by the original route are counted once.
- Reports, logs and the report dashboard now show how many additional potions a route uses and its projected HP improvement after deducting potion costs. The dashboard supports filtering and sorting by this adjusted improvement, and batch exports include the same information. Missing potion information in older reports is marked as unknown.
- Fixed predicted card-draw timing when using Cascade with Unceasing Top, reducing resulting card-selection errors and interrupted route execution.
- Fixed differences between predicted and actual end-of-turn exhaustion when Joss Paper interacts with generated cards.
- Fixed predicted hand order when Compact creates Fuel, and corrected Star-cost predictions for some cards after Bullet Time to reduce unexpected recalculations caused by those differences.
