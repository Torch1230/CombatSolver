# 0.36.0

## 简体中文

- 统一搜索模式：移除短搜与深搜的阶段区分，所有战斗直接使用完整搜索预算。自定义设置合并为一组，沿用原深搜参数；低、中、高、极高四档的时间预算分别为 60、120、180、300 秒。
- 改善长时间游玩的内存管理：减少切换用药方案时收益很小的重复回收，继续利用已经回收出的可用空间。
- 修复搭配 BaseLib、RitsuLib 时，模拟克隆反复登记空的附加信息、导致缓存膨胀的问题。自定义提示和升级数值保持正常。
- 改善卡牌与选牌界面的临时资源释放，减少长局中的清理负担。
- 自动内存回收保持后台处理；“强制释放内存”继续提供深度清理，避免搜索期间主动深度清理造成明显停顿。
- 修复加载跑局期间在线心跳可能触发的异常。
- 完善跨战斗诊断与可选性能录制。普通安装不会自动开启性能录制。

本次修复了已经定位的卡顿来源，仍在继续排查长局和房间切换中的其他停顿。

## English

- Unified search mode: removed the short/deep phase distinction. Every combat now starts with the full search budget. Custom settings use a single group and retain the previous deep-search values. Low, Medium, High, and Very High have time budgets of 60, 120, 180, and 300 seconds.
- Improved memory management during long sessions by reducing low-benefit repeated cleanup between potion plans and continuing to reuse reclaimed space.
- Fixed cache growth caused by repeatedly registering empty metadata during simulation clones with BaseLib and RitsuLib. Custom tooltips and upgrade values are preserved.
- Improved temporary resource cleanup in card and card-selection interfaces, reducing cleanup overhead during long sessions.
- Automatic memory cleanup uses background processing. Force memory release retains deep cleanup, avoiding noticeable pauses caused by proactively deep-cleaning during searches.
- Fixed an online heartbeat exception that could occur while loading a run.
- Improved diagnostics across combats and optional performance recording. Performance recording remains off by default for normal installations.

This update addresses confirmed sources of stuttering. Other pauses during long sessions and room transitions remain under investigation.
