# CombatSolver 0.35.0

## 简体中文

- 优化“瞬间”速度：玩家出牌和怪物行动均使用原生瞬间速度，仅在战斗内生效，地图、奖励和局外转场保持游戏原速。
- 修复文字特效临时对象积累的问题，减轻其对首回合发牌及长时间游玩卡顿的影响。
- 检测到皮皮极速（SpeedX）时显示性能提醒，并推荐自带战斗加速：在“设置 > 常规 > 自动执行”中，将“自动出牌速度”设为“瞬间”、“牌间额外停顿（秒）”设为 0。

## English

- Improved Instant speed: both player card plays and enemy actions now use native Instant timing during combat. Maps, rewards, and transitions outside combat retain the game's original speed.
- Fixed temporary objects accumulating from text effects, reducing their contribution to stutter during opening draws and longer play sessions.
- Added a performance notice when SpeedX is detected, with guidance for built-in combat acceleration: under Settings > General > Auto-play, set Play speed to Instant and Extra delay per action (s) to 0.
