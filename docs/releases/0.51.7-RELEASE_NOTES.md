# CombatSolver 0.51.7

## 简体中文

- 修复启用薄荷尖塔后战斗路线求解可能无法启动的问题。
- 修复求解器遇到不支持的战斗状态时，日志包也无法生成和上传的问题。

## English

- Fixed an issue that could prevent combat route search from starting when Minty Spire 2 was enabled.
- Fixed an issue that prevented log bundles from being generated and uploaded when the solver encountered an unsupported combat state.
