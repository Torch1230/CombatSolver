# 0.35.2

## 简体中文

- 修复回合开始选牌时，停止计算后无法重新计算、执行本回合或开启全自动的问题。
- 修复采用路线或应用当前回合后，界面一直显示忙碌、按钮持续变灰的问题。
- 计算期间可以手动操作选牌页面；确认选择后，求解器会舍弃过期结果并跟随当前战斗状态继续。
- 修复多个开局选牌效果连续触发，以及手动勾选部分卡牌后交给求解器执行时的接管问题。
- 改善部分复杂战斗未找到胜利路线时的后续搜索，继续使用所选档位的剩余预算。

## English

- Fixed recalculation, current-turn execution, and full auto remaining unavailable after stopping a search during turn-start card selection.
- Fixed route adoption and current-turn application leaving the interface busy with disabled buttons.
- Card-selection screens now remain interactive during calculation. Confirming a manual choice discards outdated results and lets the solver follow the current combat state.
- Fixed control handover across consecutive opening choices and when the player has already highlighted some cards before letting the solver take over.
- Improved follow-up searches in some complex combats where no winning route has been found, using the selected preset's remaining budget.
