# CombatSolver 0.51.6

## 简体中文

- 修复了上传日志包失败的问题。
- 感谢 [EEEEEEEEdison](https://github.com/EEEEEEEEdison) 提交的 [PR #249](https://github.com/Torch1230/CombatSolver/pull/249)，修复「保牌/保钱」模式漏算胖地精逃跑造成的金币奖励损失。路线摘要也会提示预计减少的金币奖励。
- 感谢 [EEEEEEEEdison](https://github.com/EEEEEEEEdison) 提交的 [PR #252](https://github.com/Torch1230/CombatSolver/pull/252)，修复同名牌在手牌不同位置时可能被当成同一种出牌方式，导致求解器漏掉会产生不同后续结果的路线。
- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #259](https://github.com/Torch1230/CombatSolver/pull/259)，修复预测时把负数伤害误算成回血的问题，并改善涉及回复效果的路线判断。
- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #258](https://github.com/Torch1230/CombatSolver/pull/258)，修复智能用药可能提前排除更省药水成本的路线，并改善已有胜利路线时的后续搜索。
- 感谢 [ky-reflection](https://github.com/ky-reflection) 提交的 [PR #242](https://github.com/Torch1230/CombatSolver/pull/242)，减少 Windows 下生成路线结果时可能出现的停顿。
- 感谢 [EEEEEEEEdison](https://github.com/EEEEEEEEdison) 提交的 [PR #251](https://github.com/Torch1230/CombatSolver/pull/251)，修复预战预测在空闲关闭时恰好收到新请求可能出现的异常。
- 感谢 [EEEEEEEEdison](https://github.com/EEEEEEEEdison) 提交的 [PR #250](https://github.com/Torch1230/CombatSolver/pull/250)，减少多张同名牌参与洗牌时的预测开销。
- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #235](https://github.com/Torch1230/CombatSolver/pull/235)，减少求解大牌组时处理卡牌效果的重复开销。

## English

- Fixed an issue that caused log bundle uploads to fail.
- [PR #249](https://github.com/Torch1230/CombatSolver/pull/249) by [EEEEEEEEdison](https://github.com/EEEEEEEEdison) fixes the gold reward calculation in “Preserve” mode when the Fat Gremlin escapes. The route summary now flags the reduced reward.
- [PR #252](https://github.com/Torch1230/CombatSolver/pull/252) by [EEEEEEEEdison](https://github.com/EEEEEEEEdison) fixes missed routes when playing identical copies from different hand positions leads to different follow-up outcomes.
- [PR #259](https://github.com/Torch1230/CombatSolver/pull/259) by [ltlly](https://github.com/ltlly) fixes negative damage being predicted as healing and improves route evaluation around healing effects.
- [PR #258](https://github.com/Torch1230/CombatSolver/pull/258) by [ltlly](https://github.com/ltlly) fixes Smart potion search discarding lower-cost routes too early and improves follow-up search once a winning route is available.
- [PR #242](https://github.com/Torch1230/CombatSolver/pull/242) by [ky-reflection](https://github.com/ky-reflection) reduces pauses that could occur when producing route results on Windows.
- [PR #251](https://github.com/Torch1230/CombatSolver/pull/251) by [EEEEEEEEdison](https://github.com/EEEEEEEEdison) fixes a pre-combat forecast error when a new request arrives as the idle worker shuts down.
- [PR #250](https://github.com/Torch1230/CombatSolver/pull/250) by [EEEEEEEEdison](https://github.com/EEEEEEEEdison) reduces simulation overhead when shuffling multiple copies of the same card.
- [PR #235](https://github.com/Torch1230/CombatSolver/pull/235) by [ltlly](https://github.com/ltlly) reduces repeated card-effect processing during searches with large decks.
