# CombatSolver 0.43.3 更新日志

## 简体中文

- 当推荐路线本回合原本就会打出“余像”时，求解器会尝试把它提前；若整条路线因此减少受伤，便采用调整后的顺序。不会为了这项调整额外打出“余像”。
- 开启战后药水掉落预测后，搜索开始时即可在路线摘要看到预计是否掉药，以及预计掉落的药水。满药栏时，只有确定会掉药且能够获得药水，才会降低这场战斗使用药水的机会成本；仅开启预测不会降低门槛。
- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #122](https://github.com/Torch1230/CombatSolver/pull/122)：修复内存回收诊断发生异常后，后续路线计算可能一直等待的问题。失败请求会正常结束，之后仍可重新计算或手动释放内存。

## English

- When the recommended route already plays After Image this turn, the solver tries moving it earlier. It uses the reordered route if doing so reduces damage taken across the fight; it does not play After Image solely for this adjustment.
- With potion reward prediction enabled, the route summary shows the expected drop—or no drop—as soon as the search starts. A full potion belt reduces the opportunity cost of using a potion only when a potion drop is confirmed and can be collected. Enabling prediction alone does not lower the threshold.
- [PR #122](https://github.com/Torch1230/CombatSolver/pull/122) by [ltlly](https://github.com/ltlly): Fixed a case where later route calculations could wait forever after a memory-reclamation diagnostic failed. The failed request now completes normally, allowing later searches and manual memory release to proceed.
