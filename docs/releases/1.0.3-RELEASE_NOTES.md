# CombatSolver 1.0.3

## 简体中文

CombatSolver 1.0.3 全面适配《杀戮尖塔 2》`v0.114.0` 单人标准、恐惧与极速模式，大幅放宽复杂战斗求解时长上限，并完成发布包安全与隐私加固。请确保同时启用 RitsuLib `0.6.16` 或更高版本。

- **全面适配《杀戮尖塔 2》v0.114.0 内容与战斗机制**：基于实机源码差分，完成新卡 **Optimism**、重做卡 **Twin Shot**（替换 **Rapid Shot**）、**My Shinies**，以及 **Fool** / 塔罗系列数十张卡牌、能力与遗物重做调整的完整模拟与搜索对齐——包含 **Growth**、**Florescence** / **The Shot**、**Tune**、**Arrow Stab**、**Recall**、**Trick Shot**、**Wah Ki**、**Wah Cho Ki**、**Punch of Joy**、**Vitriol**、**Heavy Shot**、**Quietus**（不再销毁射出的箭矢）、**Honing**、**Serrated Arrows**、**Simpleton**、**Mythic Form**、**Cho Chorus** + **Wah Blast**、**Timber**、**Blot out the Sky**、**The Fool**、**The Hierophant**、**The Sun** 等；同步修复 **Hard to Kill** / **Hardened Shell** 仅计实际扣血、**Unmovable** 与 **Adroit** / **Bounce** 格挡计数、**Stretch** 快照倍率、**Ensemble** 敌我减费与末段减层、**Happy Flower** / **Fake Happy Flower** 回合初触发时机、**Wuppy** 开局阵亡不再降费、以及攻击期延迟死亡清理。
- **最大求解时长提升至默认 30 秒、最高 600 秒**：「设置 > 性能」中的战斗最大求解时长默认由 `4` 秒调整为 `30` 秒，玩家可自定义范围扩展至 `1–600` 秒；先前保持默认 `4` 秒的旧配置会自动升级到 `30` 秒（已自定义时长的配置保持不变）。常规战斗仍会瞬间完成，复杂长线战斗可在更充裕的预算内持续深化。
- **发布包安全与隐私加固**：彻底移除进阶 10 第三幕 Boss 无伤路线的自动采集与后台上传功能及相关元数据；标准发布构建完全剥离性能采样与 PowerShell 监听代码；将无头测试轮询与测试补丁严格锁定在无头/预战子进程内运行并收紧目录沙箱；改为首次实际调用战前预测 API 时再按需固定主进程 Mod 源，并对导出问题包中的本机用户目录路径做脱敏处理。

## English

CombatSolver 1.0.3 adds full support for Slay the Spire 2 `v0.114.0` across single-player Standard, Dread, and Blitz modes, expands the max combat solve time budget, and hardens release-build security and privacy. Please ensure RitsuLib `0.6.16` or later is enabled.

- **Full STS2 v0.114.0 Content & Combat Semantics Adaptation**: Aligned simulation and search against the v0.114.0 assembly diff, covering the new card **Optimism**, reworked **Twin Shot** (replacing **Rapid Shot**), **My Shinies**, and dozens of Fool & Tarot card/power/relic reworks and balance updates—including **Growth**, **Florescence** / **The Shot**, **Tune**, **Arrow Stab**, **Recall**, **Trick Shot**, **Wah Ki**, **Wah Cho Ki**, **Punch of Joy**, **Vitriol**, **Heavy Shot**, **Quietus** (no longer destroys the fired Arrow), **Honing**, **Serrated Arrows**, **Simpleton**, **Mythic Form**, **Cho Chorus** + **Wah Blast**, **Timber**, **Blot out the Sky**, **The Fool**, **The Hierophant**, and **The Sun**; plus core fixes for **Hard to Kill** / **Hardened Shell** counting HP loss only, **Unmovable** with **Adroit** / **Bounce**, **Stretch** start-of-play snapshotting, **Ensemble** cost/decrement timing, **Happy Flower** / **Fake Happy Flower** turn-start timing, dead-at-start **Wuppy**, and deferred death cleanup while attacking.
- **Max Combat Solve Time Raised to 30s Default / 600s Cap**: Raised the default solve time limit in Settings > Performance from `4` s to `30` s and expanded the configurable range to `1–600` s (existing profiles still on the old `4` s default automatically migrate to `30` s while custom values are preserved). Simple fights still finish immediately while demanding fights have ample headroom to deepen.
- **Release Security & Privacy Hardening**: Completely removed automatic A10 Act 3 Boss showcase collection/upload and its metadata; excluded diagnostic performance recording / PowerShell watcher code from default release binaries; locked headless test polling and isolation patches strictly to headless/pre-combat worker processes with `OS.GetUserDataDir()` path sandboxing; deferred `PinMainProcessModSources` until `PreCombatForecastApi` is actually used; and sanitized `%USERPROFILE%` paths in exported bug report bundles.
