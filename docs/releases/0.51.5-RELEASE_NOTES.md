# CombatSolver 0.51.5

## 简体中文

- 修复部分平台计算或释放内存时失败的问题，并按平台显示系统内存清理按钮。
- 修复狂喜批量变牌后的手牌顺序偏差，改善跨回合路线续用。
- 修复准备时间与潜伏根系组合时的能力顺序偏差，以及覆甲、再生与灾厄的结算顺序。
- 修复狠揍自动打出群攻君王之剑时的随机序列偏差。
- 修复部分路线提前击杀全部敌人后，继续计算后续方案时发生的错误。
- 修复回合开始选牌完成后等待超时的问题，改善单步与自动执行的跨回合接续。
- 修复窥视战场后接管手牌选择时，选牌点击被忽略的问题。

## English

- Fixed calculation and memory-release failures on some platforms, and made the system memory cleanup button platform-aware.
- Fixed hand order after Ecstasy transforms multiple cards, improving route continuation across turns.
- Fixed power ordering when Prep Time and Hidden Roots interact, and corrected the resolution order of Plating, Regen and Doom.
- Fixed RNG drift when Beat Down automatically plays a Sovereign Blade that targets all enemies.
- Fixed errors when exploring follow-up actions after a route defeats all enemies early.
- Fixed timeouts after turn-start card selection, improving continuation for single-step and automatic execution.
- Fixed planned hand selections being ignored after peeking at the battlefield.
