# CombatSolver 0.34.10

## 简体中文

- 撤回 0.34.9 新增的战斗搜索目标和目标选择界面，恢复原有成长策略。
- 成长路线重新按各来源“每次收益允许付出的血量”评估，面板中的额度直接参与路线选择。
- 恢复原有搜索结束规则，取消新增的成长点数／净收益达标停止及其全自动限制。
- 保留现有成长额度与忽略收益设置；0.34.9 的搜索目标设置停止生效。
- 保留牌堆计算缓存及小刀、力量多段、消耗抽牌的组合估值改进。

## English

- Removed the combat search objectives and objective selector introduced in 0.34.9, restoring the original Growth Strategy.
- Growth routes again use each source's allowed HP cost per successful reward. The allowances shown in the panel directly affect route selection.
- Restored the original search stopping rules and removed the added growth-point / net-resource target stopping and associated auto-play restrictions.
- Existing growth allowances and the Ignore Long-Term Rewards setting are preserved. Search objective settings from 0.34.9 no longer apply.
- Retained card-pile calculation caching and improved estimates for Shivs, multi-hit attacks with Strength, and exhaust-draw combinations.
