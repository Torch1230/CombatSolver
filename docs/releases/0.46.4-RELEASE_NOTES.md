# CombatSolver 0.46.4

## 简体中文

- 感谢 [fdkgf](https://github.com/fdkgf) 在 [issue #135](https://github.com/Torch1230/CombatSolver/issues/135) 提供的建议：在已核对的放血等失血场景中，求解器会更早放弃已无法挽回战损的路线。仍有回血机会的路线继续保留。
- 精神过载带来的灾厄在下一玩家回合结束时才判定是否致死；求解器会保留在判定前击败敌人的路线。
- 修复与 Loadout 2 更新后的兼容问题：未配置怪物额外能力时，求解器可以正常搜索，不会仅因 Loadout 版本号变化而停用。配置怪物额外能力时仍会提示不兼容。

## English

- Thanks to [fdkgf](https://github.com/fdkgf) for the suggestion in [issue #135](https://github.com/Torch1230/CombatSolver/issues/135): In reviewed cases such as Bloodletting, the solver stops exploring HP-loss routes that can no longer recover the loss. Routes with a remaining chance to heal stay in the search.
- Doom from Neurosurge is checked for lethal damage at the end of the following player turn. The solver keeps routes that defeat the enemy before that check.
- Fixed compatibility after Loadout 2 updates: combat search works when no extra monster powers are configured, without rejecting a change to Loadout's version number alone. Configured monster powers still trigger an incompatibility notice.
