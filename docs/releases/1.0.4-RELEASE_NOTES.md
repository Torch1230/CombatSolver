# CombatSolver 1.0.4

## 简体中文

CombatSolver 1.0.4 正式集成由社区贡献者 `ltlly`（PR #278）开发的战斗内纯原生 Rust 并行战斗求解内核（搭配 C# `HotKernel` 全量回放校验与自动回退），新增每日挑战与全部 16 项原版修饰器支持、隐身直播自动驾驶接口及离线批量评测能力。请确保同时启用 RitsuLib `0.6.16` 或更高版本。

- **战斗内原生 Rust 并行求解内核（PR #278，感谢 `ltlly`）**：
  - 集成纯原生 Rust 战斗模拟与并行束搜索引擎（`rust-kernel/sts2_combat_rs.dll`，Release 启用 `lto = "fat"` 与单代码生成单元优化），同步适配《杀戮尖塔 2》`v0.114.0` 全实体与 1.0.3 药水/遗物/成长/首领血量策略；
  - 在「设置 > 性能」新增 **战斗内优先使用 Rust 内核** 开关，并在主界面摘要栏展示当前引擎状态（支持中英双语）；
  - 所有 Rust 求解路线在采纳与缓存前均在 C# `HotKernel` 上完成逐动作、强制药水约束与终局指标回放核验；遇游戏版本不匹配、不支持机制（如 `DistilledChaos` 触发选牌）、超时或任一回放失配均自动平滑回退至 C# `HotKernel`；
  - 协作定位保持 **C# 主干权威 + Rust 社区跟进加速**：无 `rust-kernel/` 或未来游戏版本更新时可零障碍回退至成熟 C# 引擎。
- **每日挑战（Daily）与战斗结算语义补齐**：
  - 战斗内双引擎完整支持每日挑战、自定义跑局及全部 16 项原版 `ModifierModel` 修正（含 `Murderous` 增援力量监听顺序）；
  - 修复 `SurroundedPower` 朝向编码与阵亡检查，以及 `ToolsOfTheTradePower` 等回合初选牌暂停时的 `AfterSideTurnStart` / 充能球交错触发时序。
- **隐身自动驾驶接口与离线批量评测**：
  - 新增 `STS2_AI_LIVE_MODE` 可选隐身自动驾驶 API（零界面侵入、纯内存配置、支持 `Instant` 瞬间出牌速度，默认使用成熟的 C# `HotKernel` 求解）；
  - `OfflineSearchHarness` 新增 `--eval-specs` / `--eval-stdio` 持久化批测协议、v4 战斗历史遥测及三幕双 Boss 角色注入与战后回血语义输出。

## English

CombatSolver 1.0.4 integrates the community-contributed pure-Rust parallel in-combat solver kernel by `ltlly` (PR #278) backed by full C# `HotKernel` replay verification and automatic fallback, adds Daily/Modifier support, introduces the opt-in stealth autopilot API, and expands offline batch evaluation telemetry. Please ensure RitsuLib `0.6.16` or later is enabled.

- **Native Rust Parallel In-Combat Kernel (PR #278, thanks to `ltlly`)**:
  - Bundles the native fat-LTO Rust combat simulation and parallel beam search engine (`rust-kernel/sts2_combat_rs.dll`), aligned with STS2 `v0.114.0` entities and CombatSolver 1.0.3 potion, relic, growth, and boss-HP policies.
  - Adds a **Prefer Rust kernel in combat** toggle under Settings > Performance and a live engine status badge in the overlay header (Chinese & English).
  - Every native route is verified step-by-step on C# `HotKernel`—including hard potion policy compliance, exact choice/target matching, and terminal state checks—before adoption or caching; any version mismatch, unsupported branch (such as `DistilledChaos` autoplay choices), timeout, or mismatch falls back cleanly to C# `HotKernel`.
  - C# `HotKernel` remains the authoritative baseline (and runs seamlessly when `rust-kernel/` is absent or disabled).
- **Daily Mode & Combat Semantics Fixes**:
  - Full support for Daily runs, custom runs, and all 16 vanilla `ModifierModel` rules (including `Murderous` Strength application on spawned enemies).
  - Aligned `SurroundedPower` facing/death checks and start-of-turn pause interleaving (`AfterSideTurnStart` / `OrbQueue.AfterTurnStart`) when `ToolsOfTheTradePower` suspends turn setup.
- **Stealth Autopilot API & Offline Batch Evaluation**:
  - Added opt-in `STS2_AI_LIVE_MODE` stealth API (zero overlay UI, in-memory settings, `Instant` deployment speed; conservatively defaults to C# `HotKernel`).
  - Added single-process `--eval-specs` / persistent NDJSON `--eval-stdio` evaluation, v4 combat telemetry, and Act 3 `Boss1`/`Boss2` encounter role injection with `boss_hp_relief` output in `OfflineSearchHarness`.
