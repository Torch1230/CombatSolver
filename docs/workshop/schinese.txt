[h1]战斗路线求解器 / Combat Solver[/h1]

Combat Solver 是一个面向《杀戮尖塔 2》单人模式的战斗路线求解器。

进入战斗后，它会在后台模拟当前手牌、牌堆、敌人行动、药水、遗物和跨回合状态，并在界面中展示预算范围内找到的推荐路线、预计战损与关键行动。你可以只查看建议，也可以让求解器执行当前回合，或连续接管整场战斗。

[h2]主要功能[/h2]

[list]
[*]跨回合搜索：不只计算眼前一回合，会继续预测抽牌、洗牌、敌人行动和后续资源。
[*]清晰的路线面板：按回合展示出牌、目标、选牌、药水、结束回合以及关键遗物触发。
[*]预计战损：优先比较生存、确认胜利和整场生命损失，而不是只追求当前回合伤害。
[*]逐瓶药水策略：可将当前每瓶药设为智能使用、强制使用或禁用保护，新获得的药水默认智能使用。
[*]三种使用方式：仅查看路线、执行本回合、连续全自动。
[*]随时停止计算：搜索期间可立即停止，并暂停本场后续自动搜索，直到点击重新计算。
[*]原生选牌流程：开局选牌、回合开始选牌以及抽弃牌等操作仍会显示游戏原生页面和动画。
[*]跨回合路线复用：实机状态与预测一致时直接沿用既有路线，只有状态发生实际变化时才重新搜索。
[*]搜索档位：提供低、中、高、极高和自定义配置，可按电脑性能调整时间、节点和内存预算。
[*]在线问题反馈：遇到错误路线或执行异常时，可从设置中直接上传问题包；也可以保留本地导出后手动提交。
[/list]

[h2]使用方法[/h2]

[olist]
[*]订阅并启用前置模组 RitsuLib。
[*]启用 Combat Solver 后进入一场单人战斗。
[*]等待发牌和回合开始效果结算，求解器会自动开始计算。
[*]在路线面板中查看建议，或使用“执行本回合”和“全自动”。
[/olist]

[h2]开源、许可与代码来源[/h2]

Combat Solver 的内置战斗模拟核心使用并改造了 Random Foreseer 的部分实现，现已获得原作者 [b]hotwords123[/b] 的许可。

相关来源关系持续存在于当前版本，涉及战斗状态、牌堆、RNG、Fork、History 与 Mirror 等基础逻辑。Combat Solver 在此基础上持续重构并扩展了跨回合战斗求解、路线复用、自动执行、原生选牌流程和性能控制。Combat Solver 不加载或分发 Random Foreseer 程序集作为运行时依赖；这项运行时分离不改变上述代码来源关系。

感谢 hotwords123 与 Random Foreseer 所做的工作。许可、署名和第三方来源说明会随源码及每个二进制发布包一同提供。

Random Foreseer：可在 Steam 创意工坊搜索 Random Foreseer，或在 GitHub 搜索 hotwords123/StS2.RandomForeseer。
Combat Solver 源码：在 GitHub 搜索 Torch1230/CombatSolver 即可找到。

[h2]依赖与兼容性[/h2]

[list]
[*]需要 RitsuLib 0.6.0 或更高版本。
[*]当前适配《杀戮尖塔 2》0.111.0。
[*]仅支持单人战斗，不支持多人模式。
[*]不修改游戏 RNG。
[*]搜索受所选时间、节点和内存预算限制，展示的是当前预算内找到的最佳路线，不承诺数学意义上的全局最优解。
[/list]

[h2]性能说明[/h2]

搜索会占用较多 CPU 和内存。默认使用中档与 16 GB 搜索内存；性能预设和内存预算分别保存，可按电脑资源独立调整。搜索在后台运行，并会周期性让出 CPU，尽量降低对游戏操作和动画的影响。
