[h1]战斗路线求解器 / Combat Solver[/h1]

Combat Solver 是面向《杀戮尖塔 2》单人模式的战斗路线求解器。进入战斗后，它会在后台模拟手牌、牌堆、敌人意图、药水、遗物与跨回合状态，给出推荐路线和预计整场战损。你可以只参考建议，也可以一键执行本回合，或开启全自动连续接管整场战斗。

[h2]主要功能[/h2]

[list]
[*][b]高速跨回合求解[/b]：持续预测后续抽牌、洗牌、敌人行动与资源变化，以生存、胜利和最低整场战损为目标，不只看眼前一回合。
[*][b]清晰路线与多种操作[/b]：按回合展示出牌、目标、选牌、药水与关键遗物触发，顶部汇总预计掉血与回血；支持仅查看、执行本回合、连续全自动（可选每场自动开启全自动），并可随时停止计算、采用当前候选或冻结路线；按 Ctrl+F9 快速显隐界面。
[*][b]逐瓶药水策略[/b]：在「药水」侧栏独立设置每瓶药水为智能使用、强制使用或禁用保护，并直接调整每瓶的省血阈值（按药水类型自动保存；新获得的药水默认智能使用）。
[*][b]遗物计数、成长与幕末 Boss 策略[/b]：支持开心小花、摆动球、钢笔尖、带骨肉等遗物的结束计数范围、愿付额外战损与优先级（1–3）配置；支持为各类局外成长牌配置愿付战损、一键忽略局外收益与限制至亮之焰消耗；第一二幕与最终 Boss 可分别选择通关优先或最低战损。
[*][b]原生选牌与跨回合复用[/b]：开局、回合开始及抽弃牌等选牌保留游戏原生页面与动画；实机状态与预测一致时直接沿用既有路线，只有状态变化时才重新计算。
[*][b]一键问题反馈[/b]：设置中可直接上传问题包（附带自动分类），或导出到本地后手动提交。
[/list]

[h2]使用方法[/h2]

[olist]
[*]订阅并启用前置模组 RitsuLib。
[*]启用 Combat Solver 后进入一场单人战斗。
[*]等待发牌与回合开始效果结算，求解器默认自动开始计算。
[*]直接参照面板出牌，或点击“执行本回合”／“全自动”。
[/olist]

[h2]依赖与兼容性[/h2]

[list]
[*]需要 RitsuLib 0.6.11 或更高版本。
[*]支持《杀戮尖塔 2》0.113.1 单人标准、恐惧与极速模式（兼容 0.113.0）。
[*]仅支持单人战斗，不支持多人模式，也不通用适配修改战斗内容的第三方 Mod。
[*]后台搜索绝不修改游戏 RNG。
[*]搜索受求解时长上限约束，展示的是当前预算内找到的最佳路线，不承诺数学意义上的全局最优解。
[/list]

[h2]性能说明[/h2]

全新高速低内存引擎开箱即用，无需额外内存设置。普通战斗通常瞬间出解；复杂或高战损战斗会在「战斗最大求解时长」（默认 4 秒，可设 1–15 秒）内自动逐级深化。并发线程数默认按处理器核心数自动匹配，也可在设置中手动调整或切为单线程。

[h2]在线统计[/h2]

在线统计默认开启（发送在线状态、匿名跑局统计及符合条件的进阶 10 第三幕 Boss 无伤路线），不上传普通卡组与完整路线，可在「设置 > 常规 > 在线统计」随时关闭。

[h2]开源、许可与代码来源[/h2]

Combat Solver 的内置战斗模拟核心使用并改造了 Random Foreseer 的部分实现，已获得原作者 [b]hotwords123[/b] 的许可。Random Foreseer 与 Combat Solver 均采用 MIT License。

上述代码来源关系持续存在于当前版本，涵盖战斗状态、牌堆、RNG、Fork、History 与 Mirror 等基础逻辑；Combat Solver 在此基础上持续重构并扩展了跨回合求解、路线复用、自动执行与原生选牌流程。Combat Solver 不加载或分发 Random Foreseer 程序集作为运行时依赖，运行时分离不改变上述来源关系。

感谢 hotwords123 与 Random Foreseer 的工作。完整署名、许可与第三方来源说明（THIRD_PARTY_NOTICES.md 与 LICENSE）随源码及每个二进制发布包一同提供。

Combat Solver 源码：在 GitHub 搜索 Torch1230/CombatSolver。
