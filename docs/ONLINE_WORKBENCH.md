# 监控工作台改版（2026-09-09）

## 人数变化与订阅数（2026-09-11）

概览增加所选趋势窗口的平均在线，以及小时环比（固定最近完整 60 分钟对比前 60 分钟，不随趋势视图变化）、日同比（前移 24 小时）、周同比（前移 7 天）的平均人数差与百分比。窗口截止于当前完整分钟，使用双方均有记录的对应分钟计算差值，并展示配对覆盖率；缺失不是 0，基期均值为 0 时百分比不计算。长窗口的日/周对比会重叠，界面明确标注。历史不足显示数据不足，不虚构历史。

Steam GetPublishedFileDetails 的 subscriptions 是当前订阅数，区别于 lifetime_subscriptions。服务每 10 分钟刷新一次，8 秒超时，同类请求单在途；持久缓存和采集时间在重启后保留，失败保留上次值并标记更新延迟。后台人数接口不等待 Steam 网络请求。

验证：原服务 17 项测试通过，新增 5 项计算/缓存测试通过；真实浏览器原 9 项和新增对比呈现测试通过，覆盖窄屏无横向溢出。Steam 官方接口实取 subscriptions 成功。

后台改版，不改变 Mod、战绩采集与统计计算口径。在线与战绩使用独立页签、独立表格列宽；趋势默认折叠，可保留展开状态。首屏显示在线、战斗中、跑局中和所选时段峰值。“战斗中”不等同于“正在求解”，“预计 0 HP”不等同于实测完美通关。

在线列表区分当前状态与最近完整计算结果，长昵称和战斗名截断，完整值在“详情”中可查看、选择复制。列表按稳定安装/档案 ID 更新既有行，避免整表 replaceChildren；数值零、未知和暂无样本分别展示。战绩表显示放弃包含在负场内，胜率同时显示样本量。

## 筛选与刷新

- 服务重启后前 90 秒不写历史人数，概览标注心跳恢复中，避免把空内存名单当作真实 0 人。2026-09-09 20:49:00 的 0 人点已由进程启动时间 20:49:34 及相邻 542/539 人样本确认无效，原行备份后删除；其他真实零值保留。

- 在线曲线使用单调三次插值平滑连接所有采样点，跨缺失时段也保持连续；不填造采样值，真实的 0 人样本保留。图旁注明缺失时段以连线展示。针对性浏览器测试验证包含缺口的 5 个样本仍是 5 个点、单一连续曲线，且零值与原计数不变；已检查渲染截图。

- 常用筛选：来源、运行覆盖、角色、至少完成局数。默认门槛为 5 局，始终在输入框和已应用标签中显示；可清空或点击标签移除。在线行“战绩”联查会清除该门槛，并明确显示全部覆盖类型和精确身份条件。
- 更多筛选收起：实际使用、版本、进阶、时间、指标阈值、第三方角色和精确标识。历史来源隐藏且禁用不支持的控件。草稿修改与已应用条件分开；请求失败保留上次结果及对应条件。
- 页签、已应用筛选、排序保存到 URL，可刷新恢复；自动刷新开关和趋势展开状态保存在浏览器本地。
- 在线列表 10 秒、战绩 60 秒，只自动请求当前页签的列表。可暂停/继续或立即刷新。文字选区、详情弹窗、筛选编辑、表格按钮焦点及后台标签页暂停自动更新；显式操作仍可刷新。
- 同类请求取消前一个；迟到响应不能覆盖新结果，401 统一退出，失败不清空已有数据；失败重试仍遵守更新间隔。
- 表头提供升/降序，排序在服务端先完成再分页。未知数值在两种顺序下均放末尾。在线“名次”始终是累计在线时长名次，不随着楼层或战损排序重新编号。
- 汇总明确称为“当前筛选范围”，不称全站；不使用伪置信度进度条。运行覆盖仍允许手动出牌，连续段受筛选范围约束。

## 接口增量

- `/api/players`：`sort=online|floor|hpLoss|lastSeen`，`order=asc|desc`，兼容默认 online/desc；与 q/page 共用。
- `/api/run-statistics`：新增 `order=asc|desc`，`sessionId` / `profileId` 为 32 位小写十六进制精确筛选。身份参数用绑定值筛选 SQLite；分页、总胜负及百分比全部基于相同范围。

## 验证

- `npm test`：15 项通过。新测试覆盖跨页排序、在线名次保持、身份过滤、正倒序、历史未知和零、非法参数；保留原心跳、持久登录及战绩测试。
- `npm run test:browser`：6 项真实 Edge headless 浏览器测试通过。登录恢复测试从手写 DOM mock 迁移到真实浏览器；覆盖网络失败/401、128 字符昵称、512 字符战斗名、样本门槛、编辑与应用、历史切换重置、联查、URL 恢复、暂停/文字选择、错误保留、无匹配及迟到响应。
- 浏览器测试使用本地内存服务和页面级模拟响应，未向生产接口写模拟战绩。截图位于 `.local/workbench-ui/`，已检查桌面两张截图；自动布局断言覆盖 1440px、等效 125%/150% 的 CSS 视口以及 390px 窄窗口，无页面级横向溢出，表格内部允许横向滚动。等效视口测试不是操作系统缩放实测。
- 浏览器测试依赖 Playwright。可安装在开发环境，或通过 `PLAYWRIGHT_MODULE` 指定已有包目录；`BROWSER_CHANNEL=msedge` 使用已安装 Edge，未指定时使用 Playwright Chromium。测试依赖不加入生产依赖。
