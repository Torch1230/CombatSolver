# Combat Solver v0.28.2 搜索速度与内存效率

- 优化搜索过程中的模型查询、状态统计和战斗结算开销，减少临时内存分配。贡献者基准中，同一路线的搜索速度提升约 `11%–27%`，内存分配降低约 `9%–16%`。
- 在系统或运行平台无法启用低停顿内存模式时，不再无条件把搜索限制为双线程，而是继续使用玩家设置的并行度；只有系统实际内存余量不足时才进入保守模式。
- 内存区域申请不被运行环境接受时会自动尝试较小容量，提高低停顿搜索成功启用的机会。
- 搜索批次遇到内存压力时会逐级降低并行负载，避免一次波动就长期退回最低并行度。
- 感谢時穂（Natsuki，[@s1f102500012](https://github.com/s1f102500012)）贡献本次性能优化。

适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。
