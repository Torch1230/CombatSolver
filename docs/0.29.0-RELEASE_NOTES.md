# Combat Solver v0.29.0 硬逻辑稳定性修复

- 修复搜索回放偶发找不到手牌的问题，抽牌、费用变化和最终路线回放会保持同一张卡牌实例。
- 自动执行遇到手牌变化、回合已经切换或原生选牌页面变化时，会清理旧路线并重新计算当前战斗，不再直接中止。
- 修复原生选牌页面候选变化、选择数量变化、确认按钮尚未就绪和页面超时等边界；重复计划等内部错误仍会明确提示。
- 修复洗牌触发多个选牌效果时的模拟状态冲突，按原版顺序逐项处理。
- 修复部分敌人生成路径的集合修改异常。

适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。
