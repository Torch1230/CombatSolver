# Combat Solver v0.27.1 内存监控与搜索流畅度

本版本集中改善长时间搜索的内存控制、卡顿反馈与等待体验。

- 主界面新增动态内存条，区分系统占用、游戏进程占用和剩余空间，并显示“当前内存占用 / 搜索总可用”。
- 搜索内存上限会随系统当前可用内存动态调整，避免固定预算过高后频繁触发内存整理、拖慢搜索和游戏画面。
- 无药、单药和多药搜索之间会释放上一梯度的搜索数据，再以新的内存空间继续计算；最后一个梯度结束后不会立即整理，改在战斗结束后延时清理。
- 搜索接近内存上限或正在整理时会显示明确状态，整理完成后自动继续计算。
- 搜索因时间或节点上限停止时，顶部会说明当前路线尚未彻底穷尽，并提示可在性能设置中提高对应上限。
