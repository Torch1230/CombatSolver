## 归因和撤回实验

旧 `946591ec` 与 `e9f66da0` 的同根开局对照确认：O009 85→91 HP 且新增瓶中精灵；O010 39→44 HP。合并 0.49.2 后，未改搜索基线的 O009 已为 82 HP / 瓶中精灵，不能把不同版本的 85 与 82 相减当成本次修复收益。

O009 的诊断前缀为 OFFERING → TRUE_GRIT（消耗 ASCENDERS_BANE）→ STRIKE（目标 CombatId=3）。第 3 步 Generated、TT admission、ActionAdmitted 均通过，在 GlobalRetention 中原排名 359/589，Beam 60、必需分支 56、routing 配额 24，未进入最终保留或扩展。探针未截断，24 步合法参照模拟累计 66 HP、玩家 HP13、敌方 HP0，且第 8 步 T2 Continuation 与原生记录完整相同。按消耗选牌补充后续动作多样性的候选却得到 88 HP / 瓶中精灵，因此撤回，不能把路径定位算成修复。

O006 的回合准备根先强制无主动药水，随后提前返回而不进入 Smart 审计。直接搜索允许药水的实验虽然从 combat_start 原生胜利 0 HP / 治疗 1 / 重算 0，却消耗 FORTIFIER 两瓶及 ENERGY_POTION 一瓶，默认成本合计 27 HP；既有合法单瓶路线成本为 9 HP，不能宣告资源质量通过。该实验撤回。

随后尝试为无药基线与既有逐瓶 Smart 审计分配原总预算内余量：无药基线 19 HP，监控出现 0 HP / 一瓶候选，但冷启动和预先启动实例两次均 120 秒超时、没有原生结局。逐瓶层只消费剩余节点与时间，没有抬高预算；这套编排仍未通过，因此也完整撤回。下轮应先缩小到合法的原生选牌/首个丢失边界，以诊断候选完成及收尾耗时，不再重复延长开战请求。
