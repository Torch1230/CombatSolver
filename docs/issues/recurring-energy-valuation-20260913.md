# 环绕轨道与自动化估值（未发布）

两张牌都有模拟与动作入口，但此前能力估值落在通用的单点收益，未计算持续返能。固定根的路径追踪证明候选已经生成、准入和展开，缺口在中间保路估值。新增分支局部 `RecurringEnergyGain`，环绕轨道读取按实例保存的花费余数，自动化读取剩余抽牌数。自动化包括未来自然抽牌：通常每回合5张、每10张返能一次；额外抽牌不属于启用这一收益的前提。

计算沿用已有可达牌视野（最多两轮牌堆），以当前能量、正常回合重置与牌的费用估算可消费缺口，多个实例共用缺口上限；能力/消耗牌按单次访问估算，腐化技能按免费处理。该估计是保路特征，不等于未来路线必定拿到这些能量，也不扩展原有搜索预算、终局排序或状态键。临时费用及第三方过牌引擎的长期收益仍可能低估。

## 固定对照

统一 `REGENT / AXEBOTS_NORMAL / COMBATSOLVER`，单敌人、玩家75HP、能量3，清空遗物和能力。手牌为待测能力、INFLAME、STONE_ARMOR、IRON_WAVE、POMMEL_STRIKE、SHRUG_IT_OFF、DEFEND_IRONCLAD；抽牌堆为 IRON_WAVE、STRIKE_IRONCLAD、IRON_WAVE、DEFEND_IRONCLAD、SHRUG_IT_OFF、IRON_WAVE、STRIKE_IRONCLAD、DEFEND_IRONCLAD。测试为混职业机制夹具，不是原报告整场回放。

普通质量对照固定6000节点、Beam24、单线程、60秒搜索上限，请求总上限120秒；两侧均带同样路径观察器。节点数是上限，已穷尽时可提前结束。
