# 多人分支状态与功能合同

本文件对应 `feat/multiplayer`。截至 2026-09-29，P0～P5 已按机制级完成条件收口；主线仍是单人，分支尚未正式发布。当前分支 manifest 为 0.47.2，主线已发布 0.48.0。

## 当前功能

| 项目 | 分支行为 |
| --- | --- |
| 身份 | 2～4 人，房主与加入者只决定本地动作；队友无需安装求解器 |
| 预测 | 队友不再主动出牌或用药，现有被动效果与回合结算正常推进 |
| 请求 | 多人独立政策，有限回合；单人保持整场搜索与严格续用 |
| 展示 | 输出、防守、启动最多三类实际有区别的方案，展示动作、目标和条件预测 |
| 部署 | 只执行当前本地回合；每个本地回合重新捕获并计算 |
| 外部变化 | 从新状态重评估剩余原序列；动作合法时继续，目标失效时暂停 |
| RNG | 提示共享 RNG 偏差，偏差本身不强制停牌或完整重搜 |
| 选择 | 本地选择走原版流程，队友选择由队友完成 |
| 默认界面 | 默认输出，当前回合滚动显示；后续回合可展开 |

## 已取得证据与限制

分支记录包含 37 张多人专用卡的基础/升级即时差分，以及跨玩家能力、历史、球、生成、伙伴、死亡和回合机制的代表验收。虚拟多人、本机 2/4 进程 ENet、无求解器对端及部分可见界面已有直接证据。

这些结果按机制取代表，不代表普通单人内容与随机组合逐项穷举。Steam 房间、公网延迟、Linux 游戏实机、部分死亡/选择组合以及最终可见布局仍有未验证项，保留在逐项记录中。
