# Combat Solver v0.27.0 路线交互与终局策略更新

本版本集中改进搜索过程中的路线反馈、主界面操作和幕末 Boss 的资源取舍。

- 搜索过程中持续展示当前推演路线，并区分可立即执行的当前回合与仍可能变化的后续演化路线。
- 新增“采用当前路线”，可直接保留屏幕上正在展示的方案；“停止计算”会保留停止前已经得到的路线。
- “执行本回合”与“采用当前路线”分离，减少长时间搜索时的等待。
- 等价获胜路线优先选择更早结束战斗的方案，但不会为缩短回合而增加战损、用药或牺牲长线资源。
- 设置新增自动计算开关；关闭后，进入战斗和新回合时由玩家手动开始计算。
- 第一、二幕 Boss 与最终 Boss 分别提供“通关优先”和“最低战损”设置，并在对应战斗中提示当前策略。
- 药水策略改为紧凑的右侧面板，可快速切换智能使用、保护和强制使用。
- 主界面支持拖拽缩放并记忆位置和尺寸，路线区域会随窗口高度调整。
- 修复活体雾生成的毒气弹自爆后可能导致整次路线计算失败的问题。
