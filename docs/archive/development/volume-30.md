# 开发历史卷 30

## 0.51.7 薄荷尖塔兼容与诊断取证

玩家导出的问题包与搜索初始化报出相同的 `Unreviewed native Heal patch combination.`。日志导出在抓取完整续用状态时触发治疗补丁审计，随后才会进入 HTTP 上传。

薄荷尖塔的 `RestHPRender.CatchHPChange` 挂在原生 Heal 入口，负责局外休息点回血预览。治疗审计识别补丁身份和签名，沿两种目标的战斗分支核对控制流，并检查战斗状态查询及其调用链。判定依据随安装的补丁读取，版本和 MVID 无关。未知治疗补丁组合仍由搜索入口明确拒绝。

诊断导出遇到预测语义拒绝时，记录完整续用状态缺项原因并继续归档其余材料。验证见[测试卷 30](../testing/volume-30.md)。
