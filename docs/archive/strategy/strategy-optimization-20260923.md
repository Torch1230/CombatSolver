# 更优世界线包优化记录

数值格式：预计战损 / 用药瓶数。优化前后使用同一 `combat_start` 开战根。人工结果来自站点旧报告，部分检查点、版本和用药未与当前搜索统一；“相对人工”按可核对的战损与用药分别列出，存在回血时另列最终剩余 HP，不计入同根优化量。净优化量按“优化前－优化后”计算，正数表示少损血或少用药；缺少任一可比结果时不填数字。

逐包排查从开始处理该包起累计计时。40 分钟内仍未追平人工，就记录当前数字和未解决的问题，标记跳过，继续下一包；超时包直接跳过。每次只处理一个包。
