35,784条窗口内事件中，27,983条推断纳入事件都有至少100栈帧，无缺栈/短栈。首匹配归因：监听成员重建80.83%，监听布局6.76%，Continuation约5.57%，Fork约2.97%，模型克隆约0.48%。类型估计AbstractModel数组占71.86%；最高栈47.51%落在List扩容→GetBaseHookListeners→HasKeyword→AutoPlayFromDrawPile，支持预分配候选。采样落点偏差也会把数组字节归给相邻的小视图对象，因此不据此计算单个视图大小。
