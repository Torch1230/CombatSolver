## 热点依据与实现

重新细分[上一轮实际 CPU 样本](backend-cpu-hotspots-20260908.md)，排除回放、Fork 和 Snapshot 后，`RankBest` 路径占 816 / 23,915 个搜索样本（3.41%）；其中叶子字符串哈希 118、路由父链查询 115、Beam 评分 48、字典取值 32。这里位于串行保路阶段，多次散落查表值得合并。样本数不是墙钟时间，也没有以本轮耗时倒推 CPU 百分比。

`RoutingChoiceNodes` 继承原来的有序列表，只增加五个代表引用。首次成员初始化代表；后续成员照原比较与同分规则更新。候选添加、族/选项排序、Pareto、配额及最终仲裁保持原入口与顺序。scratch 仍由 policy 租借和归还，清空唯一字典即释放各组及节点引用，不池化节点组、不跨调用缓存结果；不新增分支模型状态。

## 撤回的实验

以下均先独立构建、独立进程短搜预热后测量；不把冷启动时间列作收益。各实验源自相同基线，额外路由缓存叠加在保留的聚合版本上。

| 原型 | 正式短搜秒 | 处理 |
|---|---:|---|
| Power监听前缀边界 | 5.8465 | 收益不足，撤回 |
| 指纹小方法内联 | 5.8294 | 收益不足，撤回 |
| 原版关键词查询过滤 | 5.8681 | 短搜无收益，撤回 |
| Power插入边界 | 5.8665 | 无收益，撤回 |
| 牌列表Span填充 | 5.8691 | 无收益，撤回 |
| 共享监听尾部视图 | 5.9117 | 耗时回退，撤回 |
| 无相关附着效果的牌绕过查询 | 5.8668 | 无收益，撤回 |
| 路由签名预计算哈希 | 5.9394 | 耗时回退，撤回 |
| 聚合再加父链/评分缓存 | 5.7559 | 完整请求出现内部指标差异，撤回缓存 |

关键词原型的正常搜索为39.8507秒，但GC暂停从1,969.532降到73.945ms，足以解释全部表面收益；没有保留扩大语义面的这项修改。额外路由缓存正常搜索39.6309秒，展开/转移/选择及64条路线一致，但4项 deferred-round 诊断指标不同（83→70、22→25、1407→995、83→70）。本轮未归因差异来自调度还是缓存，不能视为完整指标等价，故撤回；不是已证实的战斗语义错误。
