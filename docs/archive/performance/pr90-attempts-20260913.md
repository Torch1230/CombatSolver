# PR #90：性能优化尝试与效果总账

本表汇总PR #89合入后的全部已记录候选、诊断实验与正式对照，覆盖`bcc15da`到`3b91d22`；随后为正式待审整合上游`ce17a40`（0.38.0）；原性能样本仍对应合并前基线，未重新测量合并产物的提速。已合入#89的探索另外列出历史入口，不重复计入#90收益。正式PR只包含保留实现；可恢复选牌执行器在[草稿#91](https://github.com/Torch1230/CombatSolver/pull/91)独立推进。

## 只评估、没有实现的方向

- 跨快照费用缓存：需要动态Power、费用历史、虚getter和第三方贡献的完整失效证明；热点只占数个百分点。
- 战斗结束判定缓存：IsCombatEnding self约1.59%，不足以支持广域死亡/召唤/Hook失效改造。
- 更深牌堆/包装COW、可变Power/变量共享：根/牌堆所有权与引用重映射成本高；已有Preview首次写克隆，不能重复计算收益。
- 共享监听后段/关键字结果：缺少具体改动对象与第三方贡献的失效证据。
- 全执行器撤销日志、紧凑字段/稀疏增量、减少并发窗口：只有条件模型，没有本轮实现或十倍证据。
- 从挂起选择直接续接：目前需新的命令阶段、事务和历史所有权；转入独立草稿。#90的稳定前缀复用没有复制挂起事务。
