# 选牌令牌与生成查询的小范围迁移（2026-09-12）

## 实现与语义边界

- `ToTokens` 按原序计数同类型/升级的前置实例，在第一次相同引用处停止；选中实例不在列表时仍计完整列表。仅当source与options确为同一对象才复用次数。赌博筹码传入手牌副本与原列表，仍分别计数。已有ChoiceCardKey缓存不再重复增加缓存。
- 卡牌GenerateToHand仍按来源引用取最新记录。药水GetSpec/Apply原来不按来源筛选，新查询不传卡牌，仍取全历史最新生成记录。保留异常、牌堆处理、克隆与费用逻辑。查询不存跨调用结果，不增加Fork状态。
