## 第一轮证据

- 包内版本：环境组装师与花样百出来自 `0.18.0`；千足虫来自 `0.17.0`；其余主要来自 `0.17.2`。旧包必须在当前源码复现后才能判定仍需修改。
- 环境组装师在第 1 回合出完牌后的实时风险复核，错误地要求下一回合暴政的 `Exhaust/Hand` 选择已经触发。
- 花样百出在第 3 回合错误地要求必备工具的 `Discard/Hand` 选择已经触发。
- 千足虫的旧版中止发生在武装已将突破升级后，部署仍按升级前计划身份匹配原生页面。
- 永世沙漏旧版在追寻打击请求弃牌堆选择时，将原版选择识别成计划外事件。
- 实验体战利品包先出现手牌已满后找不到计划中的启明星，重新计算又在战利品长线回放中失败。
- 三骑士失败包的最终路线回放首先在免费技能层数出现 `1/2` 差异；同包还记录升级牌、遗物计数和 Power 的跨回合差异。
- 计划外重算已有三个直接首差异：产卵飞虫敌方生命 `18/16`、骇鳗活力与虚弱 Power 差异、养蜂人包手牌与抽牌堆中的笨拙错位。
- 同根手操改善记录包括：女王 `64 -> 4` 与 `18 -> 8`、知识恶魔 `48 -> 1`、构装体展览 `22 -> 0`、三骑士 `31 -> 0`、永世沙漏 `25 -> 1`、实验体 `83 -> 71`、多尼斯异鸟 `55 -> 41`、另一场实验体 `20 -> 0`。当前路线文本只代表手操后重算结果，不能冒充初始求解质量。
