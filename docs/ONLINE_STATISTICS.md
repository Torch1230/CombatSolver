# 模组在线统计

## 上报与隐私

在线统计默认开启，设置页可随时关闭并自动保存。每 30 秒发送随机安装标识、平台昵称、当前角色、楼层、最近已计算战斗的敌人名称与预计累计战损、Mod 版本，以及当前跑局/战斗状态。完整路线、卡组、存档、Steam ID 与聊天内容不在心跳字段中。

最近完整结果按角色、楼层、敌人和战损整组缓存；0 损是有效值。主菜单、非战斗及新战斗尚未算完时沿用缓存，收到新结果整组替换；真实战斗状态与缓存分开。缓存随游戏进程退出清除。无头求解子进程、无人测试进程与多人跑局不上报。

同一安装标识去重，90 秒未收到心跳即离线；昵称与战斗详情不持久保存。累计在线时长与匿名战绩独立持久化。关闭统计取消请求并停止后续上报，列表最迟 90 秒后移除。安装实例数受复制配置、重装和网络影响，不能视作 Steam 官方实时人数。跑局记录与补传口径见 [跑局战绩](RUN_STATISTICS.md)。

## 客户端更新提醒

心跳成功响应可带 `{ "latestVersion": "0.35.3" }`。客户端严格按三个非负整数分量比较，服务版本较新时显示中英横幅。null、相同或较低版本清除提醒；网络失败或旧服务 HTTP 204 保留最近有效确认，非法响应记录告警。后台线程只写纯值状态，主线程刷新 UI。

提醒复用现有心跳与证书校验，受在线统计开关控制。0.35.3 之前的客户端没有该功能；关闭在线统计停止检查。最新版提示由用户在服务后台维护。

## 构建连接配置

仓库外配置或被忽略的 `.local/presence.props` 提供 `PresenceEndpoint`（HTTPS 根地址）与 `PresenceCertificateSha256`（服务证书 SHA-256），构建写入程序集元数据。没有配置的普通源码构建不启动网络上报。发布模式显式指定私有配置目录并校验连接元数据，详见 [构建入口](../tools/build/)。真实连接配置不提交。

客户端同时验证证书名称、有效期与固定指纹，禁止重定向、明文和任意证书信任。证书更换需要协调客户端信任配置；私钥仅保存在服务运行环境。

## 验证与服务边界

`ONLINE-PRESENCE-CONTRACT` 验证默认值、关闭持久化、战斗标量快照、HTTPS 和错误指纹拒绝。需要私有端点，只发送空对象并要求 400，不产生玩家心跳。普通无人场景不连接统计服务。

后台、数据库和部署由独立私有仓库 [combatsolver-presence-service](https://github.com/Torch1230/combatsolver-presence-service) 维护；主仓库保留模组客户端与其检查。
