## 下一版本（开发中）

### Q014 智能药水开局与审计截止

2026-10-06接入官方0.50.1药水机会成本政策；原生准入合同通过，同根10秒O062仍13／1／T5、O064仍14／1／T10，均零计划外重算。本批尚未全部追平，旧原生证据继续标明来源，详见逐包记录。

Windows 隔离宿主与启动器统一使用系统进程镜像路径查询，修复新进程模块路径为空时的错误拒绝。仍严格核对 PID、出生时间及私有程序路径，读取失败和无关程序保持拒绝；宿主合同及实际测试启动通过。

铁之心纳入现有持续效果开局类型；主搜索按已完成基线实测成本为现有药水层和开局后验留余量，共享节点、时间和候选容量。智能药水审计达到自身截止时保留已完成且合格的最佳路线，用户取消仍向外传播；只采用完整胜利及既有药水成本政策。旧报告仅在完整原生状态核验之后兼容缺失的默认10张手牌上限。并行展开补齐能力承诺计数汇总与复用前清零，使既有代表保护实际启用；能力偏好成员在同能力组合内优先净未兑现潜力，普通成员及跨组合排序不变。独立能力哨兵质量通过；对已正确启用保护的基线耗时−12.26%，固定250节点DOP1／DOP2动作、评分及非时序剪枝一致，真实双线程并发通过。O061–O065 逐包证据、失败试验、通用只读路径诊断和原政策验收范围见 [Q014 记录](issues/q014-route-quality.md)。

2026-10-07，已有基础分精炼成员复用安全无药胜利最后损血前边界，保持原成员宽度、排序、额度及整场取优，实验选择器和强制用药不变。O061原政策自主完整原生28→27／0／T10、零重算，追平人工战损；固定能力哨兵两版18／0／T7、零重算，候选5937.0277ms、基线6105.4608ms，单对样本未见明显耗时增加，不外推普遍提速。

同日，智能生成药水后验在已有安全无药完整胜利首回合结束后重新枚举合法选项，替换可匹配的既有生成成员，保持单成员宽度和共享预算，不追加能力复合成员；开局必用或新分支无匹配选项时沿原行为。O062原政策自主完整原生13→7／1／T3、零重算，追平合法人工。独立固定生成药水哨兵两版0／1／T4、零重算，日志确认新边界实际执行；候选4629.8855ms、基线4761.0252ms，单对样本未见明显退化。O063仍因原环境字段与模型编号材料不足阻塞，依用户要求只作本地记录。
