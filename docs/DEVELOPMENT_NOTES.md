## 下一版本（开发中）

### Q014 智能药水开局与审计截止

2026-10-06接入官方0.50.1药水机会成本政策；原生准入合同通过，同根10秒O062仍13／1／T5、O064仍14／1／T10，均零计划外重算。本批尚未全部追平，旧原生证据继续标明来源，详见逐包记录。

Windows 隔离宿主与启动器统一使用系统进程镜像路径查询，修复新进程模块路径为空时的错误拒绝。仍严格核对 PID、出生时间及私有程序路径，读取失败和无关程序保持拒绝；宿主合同及实际测试启动通过。

铁之心纳入现有持续效果开局类型；主搜索按已完成基线实测成本为现有药水层和开局后验留余量，共享节点、时间和候选容量。智能药水审计达到自身截止时保留已完成且合格的最佳路线，用户取消仍向外传播；只采用完整胜利及既有药水成本政策。旧报告仅在完整原生状态核验之后兼容缺失的默认10张手牌上限。并行展开补齐能力承诺计数汇总与复用前清零，使既有代表保护实际启用；能力偏好成员在同能力组合内优先净未兑现潜力，普通成员及跨组合排序不变。O061原生折算63→28，尚差1。独立能力哨兵质量通过；对已正确启用保护的基线耗时−12.26%，固定250节点DOP1／DOP2动作、评分及非时序剪枝一致，真实双线程并发通过。O061–O065 逐包证据、失败试验、通用只读路径诊断和原长预算未验证项见 [Q014 记录](issues/q014-route-quality.md)。
