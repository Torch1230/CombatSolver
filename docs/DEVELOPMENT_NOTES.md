## 下一版本（开发中）：检查点政策恢复与比较（2026-10-03）

报告搜索/部署恢复补齐药水奖励预测、新奇度组合、束宽组合与早期回合探索四个开关；旧 settings 和显式覆盖沿用同一字段清单。缺项搜索明确失败，不再继承本机默认开关。批量人工路线比较同时核对成长/遗物、局外收益、可接受战损停止条件及搜索开关，必要字段缺失/null 不构成政策等价；其他已记录上下文或未来字段也不能静默忽略，只允许内部预设标签不同。

此前十阶段、失败实验及 PR #206 的上游冲突解决保留于 [历史证据](issues/q003-checkpoint-policy-20261003.md) 与 [补全前开发笔记](https://github.com/jojomiseta-hub/CombatSolver/blob/b4d71450417520e61e750b96192272d589f2945b/docs/DEVELOPMENT_NOTES.md)。历史 O010 T2 三对性能属于 e9f66da0，不冒充合并 0.49.2 后重新验证。
