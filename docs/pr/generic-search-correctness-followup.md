## 已知限制

按用户在 2026-09-06 允许小幅战损/回合回退的要求，本次以所测样本最多 +5 HP 且存活获胜进行验收，并披露实际差距；这不是用户指定的精确阈值或“无质量退化”声明。外骨骼虫零损 T10 是已知限制，旧 T5 不再是本次必达目标；Smart 原政策不变，不为找回历史零损强制多用药。
