## 概要

收敛通用搜索与模拟正确性后续修复，停止新增策略实验。最终 PR 候选待正常合并最新主线（包含撤回旧 worldline 估值/保路）后验证；下列 v77 结果仅为合并前证据。不按卡牌、遗物或遭遇添加搜索特判，不扩大节点、时间或 NoGC 预算，保留主线 Smart 药水及可接受战损停止政策。

- 通用循环、区域与有序选择共用有界工作账本，跨内存检查点保留已付费用；间歇伤害按实际逐敌进展延续有限相位，每个动作仍真实模拟。
- 修正待处理选择、攻击配对事务和自动出牌嵌套选择顺序；抽牌上限只约束同步递归，不再截断整个分支的合法抽牌历史。
- 回手资格遵循原版有序牌堆与根历史，逐实例身份在 Fork 和状态键中保持；终局在原版对应的安全检查点锁定真实回合，统一回放、显示与排序。
- 失败窄搜可在原预算内重放同回合实际落选叶。票据数量和父链总量有界、模拟器正常释放，前缀工作收费，过期资格不复活。普通同分战术排序只调整没有既有保留路由的位置。
- 搜索内后台 Gen2 检查点与搜索退出后的回收完成链分离，等待明确回收完成；补齐取消、超时排空、手动请求和晚到引用释放边界。
- 补充严格路线/原版差分、纯值剪枝诊断、恢复与 GC 合同，以及隔离 headless 实例、冻结产物和静稳复用基础设施。

## 已知限制

用户在 2026-09-06 放宽回合目标并允许少量战损/回合回退，当前优先避免明显战损与严重性能退化。外骨骼虫零损 T10 是本次接受的质量限制，未找回已证明可行的旧 T5 路线；不继续为此扩大策略实验。

搜索仍是有界启发式，不保证有解必出或全局最优。恢复可能增加请求工作量；历史 GC 暂停改善不能推广为本候选全面提速。未完成全量回归、可见 Steam 卡顿、Windows 原生游戏或完整发布门禁；headless 首结果和静态门禁不能替代这些结论。
