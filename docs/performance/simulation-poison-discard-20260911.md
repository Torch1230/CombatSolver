# 中毒触发、整手弃抽与 Power 重获读取

以 `9a0589b` 为基线，紧凑实验新增 `Outbreak` 与 `CalculatedGamble`，当前准入二十一种精确卡牌类型。中毒五步原生击杀、24 个整手弃抽分支、普通抽牌哨兵和非默认 Power 重获字段均通过；本批仍未接入生产搜索，没有完整搜索加速结论。[结构化证据](simulation-poison-discard-20260911.json)

## 状态和时序

中毒触发复用现有生命／格挡与死亡值流程，但保留 `Unpowered | Unblockable`、空攻击者和空卡牌来源。伤害事件标记的高五位保存这些属性及中毒来源；下三位仍是击杀、破防和全挡结果。完成读取不把中毒记入 powered hit 或攻击完成历史。当前根拒绝 Accelerant，因此每次非零中毒只触发一次；存活后递减，死亡后清理所属 Power，末击遵守原结果牌堆与终局安全点。

整手弃抽捕获原手牌的实例列表与数量，复用每帧选择存储。结算顺序来自原版实际代码：逐牌移入弃牌堆并运行弃牌 Hook，完成全部抽牌，最后自动打出先前捕获的 Sly 实例。实例可能已在抽牌中回到手牌，仍须自动打出。新增抽牌恢复位置槽，洗牌选牌后返回正确的抽牌阶段；普通抽牌和整手弃抽使用同一方法，不重新弃牌、不重做已完成抽牌。

原版 OnPlay 未镜像而由领域补偿完成的效果，历史来源位于 OnPlay 方法作用域之外。旧投影按原 registry 分类关闭方法作用域，中毒事件保留显式来源，未修改旧历史以制造相等。补充两个实际经过的伤害后修正 Hook 准入检查。

检查重获流程时发现，数量归零后只修改旧读取模型的数量，会留下原实例的回合初始值、计时标记、Target 或动态变量。`CompletedPowerReadBinding` 现在在 lane 初始化时为非零根 Power 准备一个规范新实例，由撤销状态中的退休标记选择原实例或新实例。两组都是派生读取模型，不执行 Hook、不逐叶克隆、不写回值程序。每个非零根 Power 增加一个初始化克隆，成本需计入后续完整测量。

中毒根包含三个固定敌人，HP 为 10／40／18，格挡为 20／7／6；玩家有 50 力量与 2 虚弱，用于排除错误攻击修正。首张 Outbreak 的中毒基础值设为零，先触发既有 1／2 层中毒，覆盖归零退休；后续重新施加，再用群体中毒击杀。所有分支逐前缀比较完整状态、三个敌人、Power 顺序／附加字段、历史来源、九路 RNG、全部 Snapshot 属性和原键，包含缓存开关、撤销、逆序恢复及八个工作区。原生五步核对逐个敌人，并在清理前截取完整终局、等待真实 CombatEnded。

重获变体为初始中毒额外设置 `AmountOnTurnStart=7`、`SkipNextDurationTick=true`、`Target=player`。相同 11 分支和五步原生路线验证初始字段保留、归零后新实例默认值以及原根恢复。这是静态审查后新增的定向覆盖，没有将未运行的旧版本变体称为失败基线。

整手弃抽的复杂根是升级后的 CalculatedGamble、Sly Prepared、另外三张手牌、单张抽牌和五张弃牌，并带 ToughBandages、TheAbacus 与 Stratagem。先弃四张，抽一张后洗牌选两张，再继续剩余抽牌，最后执行 Sly Prepared 的两抽两弃；其中一个原生路径把 Sly 本身检索回手牌。24 个选择分支完整对账并在八个工作区恢复，结算格挡为 24，升级后的 Gamble 仍进入消耗堆。另用单张 Gamble 的真实根验证空手牌无抽牌／选择。

纯值 `PoisonDiscardChecks` 覆盖间接伤害属性、穿透格挡、递减／退休／重获、部分与最终死亡、完整撤销，以及部分抽牌后的洗牌恢复、重新抽到的 Sly、空手牌与八工作区。既有 Power、有序指令、生命周期、条件抽牌和九个伤害向量同轮通过。

所有游戏请求独占 headless，120 秒上限，无增量验证。v2 三请求复用同一进程，v3 单独运行，均已停止。v1 仅完成 9.57 秒构建；原生执行前补齐测试投影的通知隔离，v2 构建 9.71 秒。v3 增加重获读取模型和对应非默认字段变体，构建 9.76 秒，均零警告／错误、禁用构建安装。弃抽和普通抽牌根未使用可变基础 Power 绑定，保留其 v2 成功证据。Linux 边界门禁通过（88 个 Search 文件），PowerShell 规则同步维护但未执行。
