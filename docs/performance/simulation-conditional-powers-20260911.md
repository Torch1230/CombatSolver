# 有序群体效果与条件抽牌返回值

本批以 `65e2435` 为基线，将中毒数量、群体施加、条件抽牌和虚无完成历史纳入紧凑实验。支持卡牌从十四种增至十九种：新增 `DeadlyPoison`、`Haze`、`Snakebite`、`Defy`、`EscapePlan`。原版三敌九步和四种抽牌边界通过；生产后端尚未切换，没有新增完整搜索速度结论。[结构化证据](simulation-conditional-powers-20260911.json)

## 权威状态与顺序

- `CompactCardProgramCompiler` 从事件投影中独立出来，负责精确卡牌状态准入和不可变指令编译。执行器只识别值指令；编译器不调用效果，也不进入生产 Search/Runtime。
- `BasicPowerLayout` 增加中毒。数量、施加者、获得顺序、根槽退休与死亡移除继续进入同一撤销工作区，完成读取使用已有单向 Power 模型绑定。
- `AllEnemies` 对当前指令按原阵容顺序施加，再进入下一指令。Haze 保留“全部中毒 → 全部虚弱”，不能改为每个敌人先中毒再虚弱。移除目标由现有生命／结束门排除。
- 每个帧新增第一张实际抽牌的实例槽。`SkipIfDrawnCardNotType` 根据该返回值作有界向前跳转；子帧不共享返回值。洗牌选牌只是检索，手牌被检索填满时抽牌返回空，不能误触发条件格挡。
- 卡牌定义捕获固定类型与虚无标记。正常打出虚无牌仍要将该标记写入 `CardPlayFinished` 历史。Retain 与 Ethereal 的回合末执行尚未因此开放。

根仍拒绝未知 Hook、第三方 subscriber、费用修饰、附魔／附加状态、宠物及复杂死亡。力量、敏捷、虚弱、易伤、脆弱、中毒仅覆盖当前准入玩家阶段；主动中毒触发和回合推进另行迁移。

## 验证

`COMPACT-CONDITIONAL-POWERS-NATIVE` 使用 SILENT／CORPSE_SLUGS_NORMAL。十张初始手牌与三张抽牌覆盖 Skill／Attack／Power 返回值、升级前后条件格挡、负敏捷与脆弱取整、单体／群体中毒、原施加者保留和带中毒敌人的死亡清理。

14 组动作分支逐前缀比较：完整 `MoveStateSnapshot`、三个固定敌人、Power 附加字段／顺序、来源历史、九路 RNG、完整 Snapshot 的全部属性与原键。缓存开关、逆序恢复、撤销和八个独立执行／读取工作区一致。最后原版连续执行九步，每步完整对账。

`COMPACT-DRAW-RETURN-NATIVE` 分别建立四个真实根：无牌可抽；洗牌检索 Attack 后实际抽到 Skill；检索 Skill 后实际抽到 Attack；检索填满手牌而抽牌返回空。每个根比较完整状态、历史、九流 RNG、缓存开关／全部估值、冻结选择和撤销，再部署同一原生动作。
