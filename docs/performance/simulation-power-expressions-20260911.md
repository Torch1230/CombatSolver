# Power 条件与存活敌人求和格挡

基于 `8729341`，新增目标 Power 存在条件和存活敌人 Power 总量计算。Testing 精确准入 `BubbleBubble` 与 `Mirage`，当前为 23 种卡牌；生产搜索尚未启用此后端。没有新的整场性能结论。

## 实现

`CardEffectProgram` 保存不可变基础值与额外倍率，拒绝不支持的目标域、Power 类型、无效倍率和越界跳转。`ResumableDiscardProgram` 在指令执行时读取分支数量及当前阵容；条件沿用撤销帧的指令位置，求和采用原版有溢出检查的整数累加，然后保留 decimal 经过敏捷、脆弱和格挡边界。模型编译入口捕获变量，不读取预览后的根格挡作为执行结果。

Mirage 的消耗位置来自已准入关键词，因此普通版消耗、升级版弃牌。没有增加独立模型写入或第二套评分公式。非法动作诊断补充卡牌、目标、资源、完成与终局状态；严格快照差分在 ContinuationStamp 相同时仍报告首个不等字段，避免仅显示 `none`。
