# 灰烬之灵、死亡之舞与迅速

紧凑值执行新增灰烬之灵、死亡之舞及对应玩家能力，共 49 个精确卡牌类型；迅速附魔新增可撤销的一次性状态。灰烬之灵给虚无出牌提供非威力格挡，死亡之舞按当前解析费用判断，刺破帷幕可能在同一出牌前序列中耗尽最后一层。三者按当前能力获得顺序执行，普通牌重新查询费用，X 保留捕获的付款值。门槛在根捕获，能力仍使用原四槽状态。

迅速在抽牌前失效；选牌后恢复到附魔内部的剩余抽牌，不能重启或因已经失效而跳过。实例仍占一个槽：31 位定义编号、一位失效状态、30 位 X 与两位新增关键字。生成实例采用同一编码，付款和关键字更新保留其他字段。兼容历史单独表示附魔的 OnPlay 来源，读视图只导入私有模型并清理缓存；末击后仍失效，抽牌命令自行拒绝继续。

正常路线三根、27 次原生动作、57 分支、26 个挂起边界与三次原生附魔选择观察，覆盖能力首次／叠加、相反顺序、升级、两回合、虚无新增、X／保留、随机本地费用与附魔重用。灰烬之灵的原生选择观察确认能力已施加且迅速已失效。共享夹具使用现有开局能力构造与正式回放入口指定死亡之舞前缀；普通 Expand 没有保留这个测试前缀，未改变候选配额或预算。

嵌套自动路线为三次原生动作、10 分支、五个挂起边界：Sly 先完成自己的弃牌，再执行迅速及洗牌选择，后续推进两回合。满手／零层／已有失效状态为三次原生动作、三分支；终局为一次动作、一分支，原生清理前核对，确认先获得格挡、击杀后失效且不抽牌／洗牌。上述紧凑路线共 34 次原生动作，比较完整快照、能力生命周期、九 RNG、历史来源、完整估值、键及续用、逐实例指纹、回滚、逆序恢复、八工作区和原生推进后的冻结根。

死亡之舞另有一条原生失败基线：免费打出基础费用 2 的虚无牌，刺破帷幕先耗尽，原生格挡从 100 到 107，旧镜像仍为 100。旧镜像改为当前 GetResolved 语义，同根完整快照复测通过。固定 250 节点比较旧／新 DOP1、新 DOP2 的完整结果和续用，实际并发 2，覆盖非零挂起、取消／异常排空、根复用、未知药水拒绝及实机不变。
