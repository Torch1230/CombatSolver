# 紧凑抽牌随机费用与第二条 RNG

`Slither` 抽牌后随机费用现由紧凑值状态执行：每个受影响根卡持有可增长的有序修饰列表，`CombatEnergyCosts` 的计数及四个状态值与列表一起进入撤销工作区。只有真正抽入手牌后追加一个 0–3 的绝对费用，持续到战斗结束；打出不移除，满手停止抽牌时不取随机数。原通用 xoshiro 值类型从 `ValueShuffleRng` 改名为 `ValueRng`，洗牌与费用各自持有独立状态，随机数算法不变。

根准入要求普通 1 层 `Slither`、没有测试费用覆盖，已有本地修饰必须全部为 0–3 的绝对费用、非仅降低、在战斗结束失效。X 费用及其他修饰仍拒绝。当前生成模板不带这一效果，生成带随机费用模板仍明确拒绝；新根捕获的既有卡牌可携带完整修饰前缀。

付款及自动牌资源读取当前分支费用。事件投影只导入已提交费用值；完成读取器拥有修饰对象池，逐项重绑完整列表、更新变化金额并失效预览缓存，不执行抽牌 Hook 或取随机数。恢复短列表时移除活动后缀，池只属于当前读取器，不进入候选。原状态键新增可选 `EnergyCostRng` 覆盖，使用原字段序列；其余七流在此闭包保持不变。生产默认仍从自身 RNG 读取，没有切换后端或调整评分。

- `COMPACT-RANDOM-COSTS-NATIVE` / `98dee34da8de40eb8313653b87ddb9e9` Passed，27.50 秒。两个根／13 分支／九次原生出牌，原有修饰前缀、三次重抽中毒牌、付款、满手只抽一张、洗牌和第二条 RNG，逐步比较完整 Snapshot／原键／历史／逐卡费用与修饰字段／九流 RNG；八工作区、缓存开关及原生推进后的根隔离均通过。原生重复费用为 0、2、2，重复相同费用仍追加修饰且推进 RNG。
