# 紧凑附魔生成牌

`BLADE_OF_INK` 编译为生成固定 `Inky` 小刀模板，当前精确卡牌类型为 29 种。小刀攻击结束后按当前分支目标施加虚弱，死亡和结束门沿用基础 Power 指令。准入只接受小刀上的 1 层正常 `Inky`；其他附魔仍明确拒绝。

原版先完成整批普通小刀生成，再逐张附魔。本闭包已拒绝全部未表示的入场／生成监听器；`Inky` 没有附魔时的战斗效果，原版附魔不产生战斗历史，也不改变原比较器的类型／升级排序。因此根捕获最终附魔模板，完成状态无需新增第二套附魔执行或动态定义写入。扩展生成监听器、附魔或卡牌修改时必须重新证明这一条件，不能直接沿用折叠。

普通和附魔模板的编号不同，生成实例保留各自定义；每个读取器按实例／定义复用模型。逆序恢复同一实例编号的不同定义时，卡牌费用、附魔、消耗与完整指纹仍来自当前绑定。生成模板中的 `Inky` 属于捕获的模型元数据，候选仍只保存值。
