# 选牌执行暂停与恢复：三张牌的窄原型（2026-09-14）

已实现投掷匕首、杂技和早有准备共用的自身弃牌暂停点，优先补齐杂技／早有准备普通及升级版本。它能保留选牌前已经完成的伤害、抽牌和洗牌，从同一检查点生成独立子分支，再执行弃牌与原有出牌收尾。当前交付是独立实验工具，正常构建与默认搜索均未接入；本报告不代表完整蟹战提速。

## 暂停点与所有权

唯一程序计数位置是“手动出牌的自身弃牌尚未决定，尚未执行出牌完成”。三张牌共用一个检查点、Fork、历史重映射和恢复实现；每张牌只增加资格识别与相应夹具，抽牌张数／弃牌数量继续来自现有语义。杂技为抽 3/4、弃 1；早有准备为抽 1/2、弃 1/2。

- 检查点私有持有暂停种子、显式 frame 与已处理死亡 ID。frame 保存卡牌、目标、原生 `CardPlay`、结果牌堆、出牌前格挡、trace 和历史起点。CLR 执行作用域全部退出，不悬挂 Task、闭包或 live 战斗写入。
- 同一检查点的种子 Fork 由私有锁保护；不同子分支在锁外恢复。状态、store、活动历史后缀共用同一个 `PredictionForkContext`。活动 `CardPlay` 指向子分支 `MutablePreview`，trace、可变 `DamageResult`、攻击结果数组及抽牌原始/完成配对按身份复制；已完成历史前缀继续共享。
- 普通 `Fork()` 明确拒绝已由检查点持有的暂停种子；现有动作、抽牌、Power、死亡和选择事务断言保留。检查点 Dispose 释放种子/frame，取消或异常仅丢弃失败子分支，原异常不被清理错误覆盖，检查点仍可用于其他选择。
- 只接收 `Enchantment` / `Affliction` 均为空、单次手动执行、空显式选择游标的这三张牌自身手牌弃牌。活动 draw/damage/block 事务、带事务或外部 store、嵌套根 trace、待结算 Power/回合结束等形态均拒绝。活动历史后缀只允许已明确实现复制的风险枚举、出牌开始、伤害、攻击和已完成抽牌记录。
- 恢复通过现有选择入口消费指定选择，再调用旧路径共用的出牌完成与入堆尾部。若后续再次出现选牌，返回未完成，实验驱动丢弃该子分支并从保留父状态完整重放；多段选择计划直接走完整重放。没有用异常捕获代替资格判断，也没有失败时自行选牌。

全部实现位于 `tools/ChoiceContinuationPrototype/`。`engine.patch` 是可审查的 7 文件实验覆盖，四个 C# 文件仅由专用 builder 注入独立 worktree；正常工程已有的 `tools/**/*.cs` 排除保持生效。生产 `src/`、Search 政策、第三方登记与覆盖目录没有改动。

投掷匕首逐一核对 9 个普通弃牌结果；另验证升级牌、已完成历史前缀和真实洗牌边界。杂技普通/升级版逐一核对 9/10 个选择，早有准备逐一核对 8/36 个选择或组合，四个优先版本都对真实洗牌后的全部组合再次核对。状态对照包括完整 continuation、领域指纹、九条 RNG、有序牌堆、终局/洗牌值、完整历史载荷与 trace 图；不是只比较 HP 或历史条数。

另外验证活动开始/结束 `CardPlay`、子分支 preview 与抽牌配对的精确身份，后续兄弟修改、重访、完成后普通 Fork、父/live 不变，以及在各自子分支执行作用域内通过 barrier 强制重叠的 DOP2。投掷匕首合同覆盖执行前/执行中取消、非法选择、注入异常身份、失败后检查点重用、Dispose 弱引用释放，以及重复打出、附魔、配对 Hook 的拒绝与完整回放。三张牌均验证弃出带 Sly 语义的牌后出现第二次选择的完整回放，早有准备升级版包含外层同时弃两张。

五个计时版本各实际执行一个原生代表动作：投掷匕首、杂技/杂技+、早有准备/早有准备+。等待精确匹配的 `GameAction.CompletionTask` 结束，并比较完整 predicted/live `ContinuationStamp`；中文名称从原生本地化标题核对。原生代表证明完整结算链，全部其他组合的对照基准是既有完整模拟重放。

## 尝试记录与剩余范围

前两次合同在资格门禁失败；诊断明确定位到未纳入复制白名单的风险枚举历史记录，补齐该明确类型后通过。之后 v1/v2/v3 分别扩展基础合同、边界及保留堆，但上述旧路径诊断污染使其性能结果全部作废。最终三次修正后运行构成本报告唯一性能依据；未选择最佳单次样本、隐藏早期漂移或把多项收益相加。

本次窄原型已完成机制、状态隔离、回退与局部成本验证。下一阶段若接入默认搜索，还需要处理节点/预算记账、前缀生命周期与排空、真实搜索资格命中率，并以完整动作/路线和逐场峰值对照决定是否采用。任意卡牌调用栈、复杂 Power 事务、多层选牌的直接续接，以及完整蟹战/其他整搜收益均未实现或未验证。没有运行可见 Steam 或 Windows 性能验证；不提升版本、不发包。
