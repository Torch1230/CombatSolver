# 紧凑 Power 阶段体

`BasicPowerLayout` 现在保存每个实例的回合初始量及跳过递减标记。第四个 64 位值槽复用高 32 位保存完整有符号初始量，低位分别保存退休和跳过标志；没有为这两个字段增加工作区槽。新实例重置初始量，玩家新获虚弱／易伤／脆弱设置跳过，叠加不刷新。根上的 `StratagemPower` 也捕获为值槽，支持其回合初始字段和死亡清理；没有新增该 Power 的创建指令。

`ResumableDiscardProgram.PowerPhases` 提供三个独立阶段体：记录指定参与者的回合初始量；清除格挡并以无属性命令兑现下回合格挡；处理一侧回合末。敌方回合末先移除临时力量计数，再由自身恢复力量，随后处理全场虚弱／易伤／脆弱倒计时。递减不经过人工制品的施加修正，下回合格挡不经过敏捷／脆弱。当前闭包内没有观察这些独立递减相对顺序的回调。

Testing 单独审计 `AfterSideTurnEnd`、`AfterSideTurnEndLate` 和 `AfterBlockCleared`，只放行已表示的精确方法／类型。准入标志随冻结候选保存；未准入根及冻结副本在写入前拒绝阶段调用。完成读取绑定单向导入两个当前字段，仍由退休标志选择根模型或规范新模型，保持额外目标及动态变量的实例生命周期。
