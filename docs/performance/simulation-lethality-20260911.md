# 致死性与攻击历史窗口（2026-09-11）

致死性及其计数能力进入紧凑执行闭包，现支持 50 种精确卡牌。攻击牌开始次数使用既有预留值槽 3，不扩大固定帧或实例布局；根从冻结历史捕获，开始打牌时增加，双方回合开始时归零。暂停、撤销和冻结包含该计数。倍率在力量加值后应用，按卡牌主人判断；奥斯蒂使用自己的力量／虚弱，仍可获得玩家致死性加成。无卡牌来源的怪物伤害不获得加成，捕捉灵魂的直接失血也不消费攻击次数。当前闭包只含出牌区中首次 OnPlay，不外推到卡牌重放。

原生路线暴露了旧引擎的历史课窗口错误：分支清空上一回合最后攻击后，旧 getter 以实机玩家回合号再次查询根历史，将已过期攻击填回；此外，根捕获前本回合打出的攻击未进入当前映射。现在主线程一次捕获当前／上一玩家回合最后一张非复制攻击，随后只读取分支映射。两映射沿用现有 Fork 重映射和状态键编码，空窗口不会重新访问实机。紧凑后端仍未准入历史课遗物。

致死性三种输入分别覆盖首次施加升级牌、已有 50 层叠加升级牌、已有两次原生攻击后叠加普通牌；吊杀／虚弱／易伤、普通施伤者与奥斯蒂分别对照。每种路线推进两回合后再捕获实际新根，打出新的首次攻击并再推进一回合。总计六根、27 次原生动作、60 个分支、21 个省略选择边界、15 次原生选择计数观察和九次完整回合推进。比较完整快照、能力生命周期、逐实例状态、有序牌堆、九 RNG、历史来源、完整估值、原键和续用，并验证逆序恢复、撤销、八工作区和实机推进后的冻结根。开局能力前缀使用既有正式构造及回放入口，完整搜索仍沿用原候选政策。

历史课最小失败基线为 `9a7dcf953713474b93f31a3f1a1c1a98`：冻结当前回合原生打击后，预测下一自动阶段敌人 HP994，原版 HP988。修复后两阶段完整快照通过，第二阶段不重放复制牌，实机继续推进后复算冻结根仍相等。该夹具显式推进回合号并调用原版 AutoPrePlay Hook，包含每阶段 Fork，证明范围是两个自动阶段，不是完整战斗部署。此前致死性 Mode1 第二个后续回合的键差异也随根修复消失；诊断确认是 `_lastAttackPreviousTurn` 多出过期打击，生命／能力／牌堆／RNG／事件历史均已一致。

固定 250 节点比较旧／新 DOP1、新 DOP2 的完整结果与续用，实际并发 2；包含非零挂起、取消／异常排空、根复用、未知药水拒绝和实机不变。纯值全套合同通过；新增零／非零根历史、外层未结束时零命中内层攻击、来源门禁、暂停、撤销和八工作区。第一版合成测试使用了未准入的定向 Sly 攻击，被构造器正确拒绝；改成零命中内层攻击后通过，没有扩大生产闭包。
