# 奥斯蒂根身份与死亡能力清理

继续迁移亡灵完整域前，最小原生对照发现两处旧引擎偏差，现已修正。

- 根没有奥斯蒂时，`GetOsty` 会回落到实时 `player.Osty`，实机首次召唤后导致冻结根获得原本不存在的宠物。主线程现在同时捕获每个玩家的宠物身份或明确空值，随 Fork 不可变共享；分支召唤仍拥有自己的生成身份／最大生命映射。回合开始计数也改为读取分支宠物，未知玩家不会读取 live。
- 通用死亡入口只清理玩家，敌人由领域死亡扫描清理，奥斯蒂不在两条路径内。死亡后的力量因而留到复活后。现在宠物在 `AfterDeath` 后通过内部效果合同调用既有 `RemovePowersAfterDeath`，普通能力退休、`DieForYouPower` 保留；其死亡阵容判定也保留该代伤能力的原生约束。不会把宠物当作敌人移除或引入敌人复活 AI 状态。
