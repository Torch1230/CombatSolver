# 模拟性能方案决策账本（2026-09-11）

[性能目录](README.md) · [上一轮估值诊断](simulation-evaluation-bottleneck-20260911.md)

本账本汇总此前方案和本轮剩余评估，区分保留、撤回、不进入、进入实现和接入后验收。评估完成表示已有下一步决策，不表示尚未实现的后端已通过完整战斗、内存或并行验收。当前生产搜索仍使用原模拟引擎；实验后端仅覆盖明确准入的抽牌/弃牌闭包。

本批扩展已加入 Shuffle 五字段、战略选牌、遗物格挡与防御／后空翻，详见[执行扩展结果](simulation-expanded-chain-20260911.md)。不变特征缓存保留原公式；原生两回合采用旧回合推进，不能据此宣称紧凑 Power 数量、伤害、死亡或完整 Beam 已迁移。含每批准入的局部结果为 3.31×／分配 −80.65%，完整搜索目标仍待验证。

## 剩余五项评估与本轮实施顺序

| 项目 | 当前证据、限制与决策 |
| --- | --- |
| 冻结与恢复 | 旧候选每叶分配 4,680 B；恢复还构造稠密工作区及事务缓冲。新链接源码探针的 34 叶仅 49–68 个非零槽，总容量 573 槽。进入分块不可变候选与同根闲置工作区恢复；保留完整槽值，不能删除暂停栈或历史来省内存 |
| 长路径/历史 | 生产 `CombatPredictionHistory` 已有不可变前缀，不算新优化。原型事件带容量有限，尚不支持完整跨回合历史。结构探针以 0/1,024/8,192 个历史值、128 个保留候选测冻结增长；选择共享不可变页以避免复制未变化前缀，不截断语义历史。生产长路线读取和原生事件身份仍在后续闭包验收中 |
| 复杂 Power/RNG/死亡写入密度 | 现有真实逐类型数据见 P4；新增[原生净变化补测](simulation-read-view-20260911.md)覆盖混合 Power 与召唤／击杀后跨回合、两条变化的完整 RNG。它是稳定边界观测，不是实际写次数／dirty page 比例。当前已纳入 Shuffle 和战略的固定数量触发，Power 数量变化与死亡仍显式拒绝；不能拿旧闭包的 49–68 个非零槽代表复杂战斗。新存储探针覆盖 8/512/1,024 槽写入，判断密集退化；它测表示成本，不实现游戏效果。保留原生克隆链，待权威读写入口完整迁移后才测真实 dirty page/首写率 |
| Beam 存活量与 GC | P5 当前生产行为基线已测：机甲/亡灵 RSS 均值约 +15.05%/+19.33%，最坏 GC 暂停 B 为 1,938.05 ms，无最坏暂停改善证据。当前无新后端 Beam 接线，不能声称其生产存活量已测。先让候选只持不可变值页、复用 lane；接入后必须量峰值存活图、RSS、GC、父链及剪枝后释放，不能用分配量替代 |
| 并行扩展 | 09-08 DOP8 约 3.20–3.38× 曲线早于已准入作业等改动，不能代表当前版本。本轮补当前构建 DOP8→1→2→4→8 固定短搜；仅作当前瓶颈基线，冻结存储本身不修改生产 lane/调度。新存储另验证同一冻结句柄的 8 worker 独立恢复与失败/取消隔离 |

第一批实现只改变紧凑执行器的候选保存/恢复边界。采用固定值页、私有不可变页内容、独占工作区及页失效；原地写入和 rollback 均失效对应页，Freeze 发布独立页表，Restore 只接受同根且无活动事务的工作区。不建立祖先差量链，不让 coordinator 持有 lane 指针。长历史共享减少复制，页表长度和恢复扫描仍随状态容量增长，这一代价需要报告。

**第一批现已实现并保留。** [交错对照和原生验证](simulation-candidate-storage-20260911.md)记录：34 叶展开/冻结分配 −77.03%、CPU +14.79%；同根复用恢复零分配，该批次时的完整原型仍需逐叶旧图物化。浅密集负载 CPU 约 +49%–52%，不能直接扩展到完整复杂效果。当前 DOP8 实测 3.94–4.25 秒、DOP1 13.82 秒，34 项逻辑指标相同；没有新的调度改动或生产加速声明。后续读取迁移现已完成同一封闭场景的直接读取入口，详见[下一批结果](simulation-read-view-20260911.md)；生产和复杂效果尚未迁移。

稀疏独立索引压缩虽可把本 fixture 的数据压至约 588–816 B，却会在每次冻结重复复制整段历史；单纯裁去尾零仍需复制 305–316 槽。固定不可变页同时处理保留候选、长历史和 worker 恢复，因此先实施此边界，再根据实际稀疏/密集结果决定保留。只有冻结/恢复正确性和分配证据通过后，才将其记为保留实现。

本轮未调整 Beam、时间/节点/选择预算、药水政策、状态键、默认 DOP 或 NoGC 大小。用户只要求 headless；不补可见 Steam 性能结论。

## 直接读取完成后的下一步

读取合同已通过同一抽弃牌闭包的完整差分；完整批次约 2.87×、分配为旧动作重放的 16.53%，CPU 3× 联合门槛仍未通过。根仍提供闭包内不变元数据。后续优先逐个迁移复杂效果的字段权威、写入和撤销，再测真实 dirty page／字节复制；不把当前读取器接到任意分支。生产 Beam 的新候选存活量／GC 与新后端 DOP 仍需要接线后验收，不能以本轮每叶分配替代。增量估值留在完整读取之后单独评估；新键、预算和政策改写继续不进入。
