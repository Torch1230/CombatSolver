# 紧凑临时力量与尖啸

基于 `672e25e` 的原生语义修复，编译器新增尖啸普通／升级状态及消耗；当前支持 26 种精确卡牌类型。临时力量减少指令仅准入敌方尖啸计数、非负整数请求和单体／群体目标。

## 状态与执行

`BasicPowerLayout` 新增 `PiercingWail`，适配器只为敌人准备该计数槽。数量、顺序、施加者和根实例退休沿用原有值布局。执行每个目标时，首次 Strength 命令先于临时计数加入；随后按原生请求偏移与当前计数比较，覆盖计数封顶后依然减力量的语义。整根只放行精确 `PiercingWailPower.AfterPowerAmountChanged`，其他未迁移 Hook 保持明确拒绝。

原有群体顺序、死亡清理、值读取、逆序恢复及八工作区隔离共同覆盖新计数。`UnattendedTestRunner.CompactCardSequences` 共用无单体目标卡牌的每前缀完整状态／历史／九 RNG／原键／Snapshot 对照，供下回合计数与本夹具使用，避免复制同一套验证。

## 验证范围

纯值合同覆盖首次施加、已有计数封顶、叠加、力量退休重获、施加者／顺序、消耗、死亡、撤销与八工作区。原生请求有两个根：普通／升级尖啸作用于初始力量归零及空 Power 的三敌；另有封顶计数、非默认回合初始字段，并以中毒击杀第三个敌人。每根分别枚举单牌、正序及逆序，完整比较原引擎、事件投影、缓存开关读取和每个固定敌人快照。

卡牌完成后使用旧引擎及原生定向侧回合末回调验证恢复；这仍不是紧凑回合推进。完整原输入的生成卡、复杂 Power、怪物行动、生产接入及整场 A/B 尚待完成，本批没有整场提速结论。
