# 奥斯蒂每回合召唤

精确 `BoundPhylactery` 现可在已有奥斯蒂、完整回合准入的根中运行。原版使用 `AfterEnergyResetLate`，使早期依赖宠物存在状态的效果先执行，再在抽牌前召唤。新执行从根捕获非负整数召唤量，能量重置后调用与卡牌相同的 `SummonPet` 值命令；随后才创建可暂停的抽牌／弃牌帧，不会在恢复选择时重复召唤。

战前首次召唤属于捕获前状态；没有宠物、未迁移观察者、熔毁遗物和不含完整回合的域继续明确拒绝。没有新建镜像注册表或第三方登记入口，也没有改变旧引擎已有的后置能量重置时点。

有格挡保护的存活根第一次回合后宠物为 6/8，后续受击死亡后复活为 1/1，再增长为 2/2；另外两个根得到 1/1、1/1、2/2。原生与紧凑逐项相同，完整中间态对照也通过。不是仅按最终 HP 判断一致。
