机甲的四对收益与分配下降支持保留；亡灵收益较小。两场首尾基线本身变快约 19.17% / 15.38%，因此不将均值变化当作精确通用倍率。分配减少也没有变成进程 RSS 均值下降；预热后的既有堆和回收时点包含在采样中，没有证据把 RSS 增幅归因于某个单一因素。亡灵最坏 GC 暂停约 1.924 → 1.938 秒，未改善。完整分布、配对、工作量及局限见 [P5 报告](simulation-refactor-p5-20260910.md)。**没有达到 10×，也没有可见 FPS 或实际画面流畅度结论。**
