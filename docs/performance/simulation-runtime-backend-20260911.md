# 紧凑后端的运行时准入与 NoGC 对照

Runtime 现在由 `SearchBackendPolicy` 在主线程从完整捕获根选择后端。精确原生卡牌／Power／遗物／附魔、机械骑士 AI、根历史与所有可达生成模板均需通过已有闭包；全部非空药水槽当前拒绝。未迁移域、初始准备和增量诊断保留模型后端，日志记录原因。只有准入构造中的 `NotSupportedException` 代表后端不适用；执行和读取错误不回退，不逐候选混合状态。
