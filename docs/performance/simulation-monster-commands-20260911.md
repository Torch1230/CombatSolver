# 紧凑机械骑士指令体

紧凑值程序现在执行 `MechaKnight` 的四种已捕获指令体：冲锋攻击、喷火攻击后生成四张灼伤、获得格挡后施加力量、重击。Testing 只准入单个精确类型的机械骑士，攻击值从根已经捕获的怪物静态参数取得；不在 worker 读取实机难度或意图。`MonsterEffectProgram` 私有复制指令数组，候选共享不可变配置，生命／格挡、Power、生成实例、牌堆和历史仍属于同一撤销状态。

`ResumableDiscardProgram.Monsters` 复用基础攻击、格挡、力量和生成卡指令。怪物事件使用独立的负来源编号，生成事件仍标识新卡实例，并显式区分玩家创建者与空创建者。喷火致死后生成命令被结束门拒绝；存活时满手溢出的灼伤进入弃牌堆，之后可以洗牌、抽入和执行手牌末尾效果。玩家的斗篷与匕首生成、打出及消耗小刀也经过同一事件格式。

旧投影只解码事件：怪物伤害保留攻击者、无卡牌来源和怪物行动伤害来源；攻击完成属于对应怪物。`CombatHistoryReadValues.CreatureAttacks` 扩展完整读取合同，原指纹编码器支持整张已提供映射，同时保留旧玩家单项替换以及缺席／零值区别。读取器从隔离初始化副本取得各怪物的历史初值，增量计数、累计玩家失血和完整估值均消费当前值事件。生产默认调用不提供此映射，行为不变。
