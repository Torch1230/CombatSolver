# 预借时间与刺破帷幕费用

紧凑值执行新增预借时间、刺破帷幕及对应玩家能力，精确卡牌闭包共 44 种。费用按本地修饰、预借时间加费、刺破帷幕免费依次计算；免费只适用于当前手牌／出牌区中的虚无牌。负基础费用和 X 跳过全局修改，付款值独立保存在执行帧中，免费层数在出牌开始前递减。预借时间在玩家回合结束时移除，刺破帷幕可继续保留。

完成评估新增内部只读费用来源，每个工作区按当前实例读取权威值程序。评估模型保留的根牌堆位置不能用于这些查询；本地修饰列表、全局费用和 X 付款分别核对。来源不进入候选，也不复制到模型 Fork。

原生对照另外发现两处旧引擎偏差并修正：

- 选牌挂起门禁此前会阻断同步费用 Hook。已有一层刺破帷幕时，三张虚无牌在下一回合选择中被错误地按 1 费估值。现两阶段能量费用查询仍读取当前挂起状态，其他效果 Hook 默认继续暂停。原生选择现场额外验证免费费用。
- 参数化能力规格在最后一击后仍施加后续能力。共同施加器现在对每条能力命令检查结束门禁，与原版 PowerCmd.Apply 一致；其他资源／生成命令仍按自己的规则执行。结束后全局费用 Hook 也不再应用。
