候选准入准备56.6–134.9ms；其中部分先完成一次小堆阻塞收集，再确认后台可用。候选搜索后异步清理370.8–647.2ms，发生在搜索完成后，不等同于这些时长全部暂停线程；日志记录的清理累计GC暂停为3.5–5.6ms。测试框架在最终捕获配置前等待该清理，而玩家结果回调没有以它作为全部完成条件。包含建局的每份请求总耗时仍保留于JSON。

候选搜索内重建阶段最大日志耗时5.1ms；它包含诊断尾部，不是严格线程暂停。此次没有对24份性能请求挂EventPipe，不能用GC累计计数证明全部线程暂停都已覆盖；此前严格线程暂停跟踪见[Windows修复报告](windows-gc-background-transition-20260920.md)。
