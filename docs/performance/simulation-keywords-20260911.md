# 雕琢打击、响指与动态关键字

紧凑值执行新增雕琢打击和响指，共 47 个精确卡牌类型。两者分别在玩家攻击／奥斯蒂攻击之后给选中手牌增加虚无／保留；奥斯蒂缺席只跳过攻击。原有局部关键字保存在定义中，新增标记随实例撤销状态保存，付款更新 X 时保留标记。状态使用原实例槽，30 位 X 与两位关键字各自独立。

选牌过滤读取当前分支关键字。完整来源与可选集合分别保留，按 OptionOccurrence 回放过滤后的同名牌，SourceOccurrence 继续表示其来源身份。模型读取器只导入私有预览，恢复旧候选时移除后加标记、清理缓存；费用、打出历史、虚无消耗和保留统一读取当前值。未增加关键字的闭包跳过导入，普通选择不额外分配过滤数组。全局关键字修改、临时保留与任意关键字增删仍不在本次准入内。

正常路线为三根、13 原生动作、38 分支、18 挂起边界与五次原生选择观察，覆盖 X 同时保有两种标记、同名牌过滤、已有标记、普通／升级及死宠物。生成牌路线为六原生动作、15 分支、六挂起，验证独立生成身份及虚无优先于保留；空选择为两原生动作，分别覆盖全部选项被过滤和空手牌。路线均比较完整快照、能力生命周期、九 RNG、历史来源、全部估值、键／续用、逐实例指纹、撤销、逆序恢复、八工作区和原生后的冻结根。
