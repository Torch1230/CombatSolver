# 有序卡牌指令与选择续执行（2026-09-11）

[性能目录](README.md) · [基础 Power 阶段](simulation-compact-powers-20260911.md) · [原始证据](simulation-effect-program-20260911.json)

紧凑执行器改为运行每张卡牌的有序指令，新增生存者的格挡后弃牌。原有攻击、中和、格挡、抽弃牌、自动出牌和洗牌共用相同执行游标。三个原生场景均通过完整状态和估值对照；生产搜索仍使用原后端。

## 表示与恢复

`CardEffectProgram` 保存私有复制的不可变指令数组，操作目前为目标攻击、格挡、抽牌、弃牌与目标虚弱。卡牌定义只持有费用、指令和 Sly 标志，不再用不断增加的标量字段隐含固定效果顺序。未知操作或越界参数在根执行前拒绝。Testing 仍负责核对原版类型、逐实例状态与完整 Hook 准入，通用执行器不认识卡牌类型。

每个执行帧增加一个指令索引，同付款、选择列表、抽牌进度、父子帧和事件一起写入撤销槽。洗牌选牌后继续当前抽牌指令；抽牌指令结束才清零自己的进度。批量弃牌先移动全部选中实例并执行弃牌触发，再依序完成自动牌；自动牌返回后，父牌继续下一条指令。指令数组不持有 worker、模型或回调，冻结候选只共享不可变定义。末击后的格挡／抽牌遵守对应结束门，牌堆结束门继续保留。

已准入卡牌由适配器明确编译：生存者为格挡→弃一张，后空翻为格挡→抽牌，中和为攻击→施加虚弱。零基础格挡仍保留一条格挡指令，接受敏捷修正。没有弃牌效果的牌不再制造空弃牌事件；真正的空选择仍完成自身指令并继续后续效果。完整历史、原键与风险比较均保留。
