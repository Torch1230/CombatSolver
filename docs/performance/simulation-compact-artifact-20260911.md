# 紧凑人工制品与 Power 准入顺序

紧凑域新增 `ArtifactPower` 的捕获值槽、消耗、归零退休与死亡清理。仅原根存在的实例分配槽位，因为目前没有准入创建人工制品的指令。根内没有该 Power 时，程序沿无人工制品的原路径处理。

`PreparePower` 负责零值、结束／死亡门和人工制品修改；`CommitPower` 负责实际数量、施加者、获得序列及事件。可见负面计数和负属性请求消耗一个人工制品并拒绝本次施加，正增益不消耗。尖啸的外层计数先通过修改；首次内部扣力量随后执行，计数使用已准备的提交入口，不能再次应用修改。这对应原版 BeforeApplied 之前的修正顺序，避免先扣力量后才挡住外层效果。已有临时计数被阻止时，也不执行后续扣力量回调。

整根 Hook 审计补入真实的 `TryModifyPowerAmountGiven`／`TryModifyPowerAmountReceived` 名称，并只允许已表示的人工制品修改与消耗回调。其他 Power 不因此获得准入。读取器继续使用原 Power 元数据、退休值和完整有效顺序。
