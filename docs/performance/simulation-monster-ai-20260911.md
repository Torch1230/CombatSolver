# 紧凑确定性怪物 AI

`DeterministicMonsterAi` 在根准入时私有复制整数后继、当前招式索引和日志。`DeterministicMonsterAiLayout` 将当前索引与可增长日志保存在同一可撤销工作区，候选共享不可变布局；恢复后不读取原生当前招式或日志，也不消费 RNG。

Testing 只准入单个精确 `MechaKnight` 的四节点图：CHARGE → FLAMETHROWER → WINDUP → HEAVY_CLEAVE → FLAMETHROWER。检查节点类型、后继、无需首次强制完成的标志、初始选择已完成和隐藏计数；异常图在执行前拒绝。`AdvanceMonsterMove` 对应已经完成招式后的选择边界，不重复执行命令体，不代替完整回合驱动。

每个读取器在初始化时准备四个旧 AI 记录及私有日志。读取完成候选时只导入当前索引、日志和意图，沿用原 Snapshot、状态键、续用文本和估值；不逐叶构造记录，不调用旧 AI，也不把读取器保存在候选中。该初始化与日志导入仍有成本，本项未测量速度。

原生 `MonsterModel.PerformMove` 还写入 `MonsterPerformedMoveEntry`；当前游戏对此条目没有战斗语义消费者，现有预测历史合同也不表示该条目。原生测试单独核对其招式、目标与数量，保留现有完整伤害／攻击／生成来源历史，未为增加条目而改变原估值的历史计数。`_isWoundUp` 仍仅参与动画选择，不是遗漏的战斗私有状态。
