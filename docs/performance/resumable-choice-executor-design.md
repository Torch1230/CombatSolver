# 可恢复选牌执行器：独立草稿设计

状态：设计与成本评估；尚无执行器实现、测试通过或新性能收益。用户于2026-09-13要求把已完成优化转为正式PR，并为此改造单独建立草稿。前置实现及实验见[PR #90](https://github.com/Torch1230/CombatSolver/pull/90)。本草稿从上游`ce17a40`建立，先只提交设计，避免重复带入#90；接入前先吸收#90的最终合入版本，重新检查相关语义。

## 问题与目标

现有选择回放遇到挂起选择后从动作起点重新执行。#90只能复用无挂起事务的EndTurn抽牌后稳定前缀；本设计研究保存明确的执行阶段，使同一选择的兄弟分支各自复制状态后执行剩余步骤。

最终目标仍是同一女王原包自定义Beam512、100000节点、出牌100/牌堆42/手牌54、300秒上限、Smart原两药水槽、DOP16/NoGC16GB的完整请求小于10秒，保持决策质量。#90最终候选在120秒无人请求上限超时；20000节点单主搜索21.257秒不能代替完整验收。该目标尚无可兑现保证，先证明局部原型收益，再决定后续投入。

## 首阶段范围与状态所有权

先选一个实际高频的原版抽弃牌来源，盘点其完整调用链及间接触发；不要仅根据卡牌名称建立永远适用的快捷路径。原型限定已证明可续接的命令路径，其他来源保留完整回放。首阶段不推广通用自动出牌/任意第三方Hook，不移植Compact后端、不改变搜索政策或预算。

| 职责 | 拟改动 | 所有权与不变量 |
| --- | --- | --- |
| Simulation命令执行 | 用显式阶段和待处理项描述暂停点，优先抽/弃牌链 | 每个分支拥有执行帧；不复制CLR调用栈、Task、闭包或live模型可变值 |
| 选牌协议 | 保存选择来源、上下文、时机、当前序号 | 保持原合法选项、物理实例身份、嵌套顺序和消费次数 |
| Fork及历史 | 定义可复制的暂停边界和未完成历史表示 | 共用PredictionForkContext重映射；不删除AssertForkable来放行原本不安全的状态 |
| 搜索回放 | 保存父动作内的暂停状态，兄弟分支各自复制续接 | 动态配额与原序提交仍由唯一消费者管理；逻辑转移计数不能因少做物理回放而改变 |
| 生命周期 | 取消、错误、兄弟完成、无后续选择时释放 | 先排空生产者再释放父状态；异常传播，不跳过未知行为 |

必须显式保存并核对：循环处理位置、待自动出牌队列、伤害/抽牌来源、已执行与未执行Hook、选择游标、历史未完成项、九条RNG状态与计数。具体帧字段由首个来源调用链决定，不能预先把所有执行状态装入通用字典。

## 分阶段成本估算

代码量指新增及修改的生产/测试代码，不含生成物和文档；以下不是交付时限承诺。

| 范围 | 生产代码 | 测试代码 | 文件数 | 单人工程量 |
| --- | ---: | ---: | ---: | ---: |
| 一种抽弃牌流程原型 | 500–1000行 | 300–800行 | 6–10 | 2–4人日 |
| 覆盖该局主要路径、其余完整回放 | 1800–3500行 | 1200–2500行 | 12–22 | 1–3人周 |
| 通用嵌套/自动出牌/复杂触发 | 5000–10000+行 | 3000–6000+行 | 25–45+ | 4–8+人周 |

当前只启动设计与第一档原型的范围。第二/三档是后续评估，不作为已承诺实现。主要成本是证明不漏结算、不重复触发、分支不互相污染，以及维护完整回放后备路径。

## 验证与继续条件

1. 先建立原完整回放的独立对照。逐个选择比较完整状态/ContinuationStamp、所有有序牌堆和逐实例状态、Power、怪物AI、RNG、历史内容与顺序、累计路线标签及边界；不能仅比较评分、HP或历史数量。
2. 多兄弟分别写入、重访首个兄弟、父/root/live不变；覆盖空选、多选、嵌套、抽牌洗牌、弃牌触发、死亡/战斗结束和失败清理。未支持的组合回到完整回放，并验证该后备确实执行。
3. DOP1/DOP2完整动作、非调度结果字段及原逻辑预算消耗一致；取消/异常必须排空。所有权改变后先做最小边界合同，不把性能测试和增量验证混跑。
4. 固定同一输入、源码基线、政策和DOP/NoGC，用无插桩A-B-B-A量化总搜索耗时、物理重放/续接次数、累计分配及峰值；记录全部负向样本。收益必须超过基线波动且方向一致；不按局部scope节省推算十倍。
5. 原型没有收益、收益低于噪声、或正确性需要无界扩大支持面时，记录并撤回原型；保持草稿，重新评估投入。
6. 最终候选才验证原包完整配置。仍遵守单请求120秒上限，不缩预算、关药水审计或延长超时伪造达标。Linux数据不外推Windows可见表现；本批仍不启动可见Steam、不发版。
