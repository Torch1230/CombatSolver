# 亡灵卡牌操作与终局生成

紧凑值执行新增捕捉灵魂、坟冢爆射、玷污、鬼火与进阶之灾，包含升级变量、虚无与保留。捕捉灵魂的直接生命损失保留卡牌／施伤者来源，但不受力量、格挡修正，也不计作攻击；随后复用逐张随机生成。坟冢爆射的弃牌堆回收在攻击后建立独立选择边界，保留正式实例与来源匹配。

终局验证发现并修正了两个区别：

- 原版生成命令在战斗仍进行时记录生成历史，实际入堆另外检查战斗是否正在结束。捕捉灵魂击杀最后一个敌人后，三张灵魂仍有生成身份／历史，均未入堆，不消费插入 RNG。新增 `Unplaced` 值集合表示这一状态，与已移除卡牌分开。怪物预览生成入口另有接收者存活检查，玩家死亡后不创建灼伤。
- 原版弃牌堆选择在战斗结束时直接返回空结果。旧引擎的坟冢爆射规格此前仍产生选择，实际部署时无法消费；现同步修正旧规格和紧凑执行器，最后击杀后不再产生这一选择。

所有路线对照完整快照、能力元数据、九 RNG、历史来源、全部估值字段、原键／续用、撤销／逆序／八工作区及实机推进后的冻结根。普通牌与已入堆生成牌核对完整旧／新／原生指纹；旧引擎对未入堆牌只保留不可变标量历史，因此先核对其身份、类型、升级和所有者，再将值模板的完整指纹与原生实例比较。

迭代记录没有删去失败：v1 普通两回合通过，但两种终局与旧引擎不一致；v2 构建发现历史标量快照不能当作可变卡牌对象；v3 修正生成身份后，原生胜利清理阶段发生进程崩溃，未产生测试结果。v4 改用既有清理前观察器，捕捉灵魂通过，坟冢爆射则暴露旧规格的多余选择；v5 修正该规格。捕捉灵魂在 v4 通过后，其行为输入未变，沿用直接证据。各 runId、失败原文、构建记录及逐步牌堆／宠物／RNG 见[结构化记录](simulation-necro-card-operations-20260911.json)。
