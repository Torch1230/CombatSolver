# 挽歌与灵魂的值执行

精确 `Dirge`（挽歌）和 `Soul`（灵魂）加入已有宠物根的紧凑执行域。挽歌先按捕获的 X 值逐次召唤，再逐张生成灵魂并随机插入抽牌堆；升级版使用升级灵魂模板。灵魂抽牌后消耗自身。X=0 不召唤、不生成，也不消耗随机数。

随机插入与洗牌使用同一条 Shuffle RNG。每张生成牌都推进一次，包括空牌堆的第一个位置；插入不增加洗牌事件数。值事件保存目标牌堆和实际位置，模板从不可变实例定义解析。兼容投影恢复该位置，避免重抽随机数。生成与升级观察者仍由整根门禁约束；当前模板折叠仅用于已证明没有相关观察者的根。
